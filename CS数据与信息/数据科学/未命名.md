这是一份为您整理的**数据科学数据处理流程笔记**。整个流程不仅包含了标准的数据科学生命周期，还详细拆解了在不同数据类型（结构化/时序/文本/图像）和不同任务目标（分类/回归/聚类等）下，各个流程的具体处理差异和技巧。

# 📊 数据科学数据处理全流程笔记
## 核心流程总览 (CRISP-DM 标准模型)
1. 业务理解与问题定义
2. 数据收集
3. 数据清洗与预处理
4. 探索性数据分析 (EDA)
5. 特征工程
6. 模型建立与训练
7. 模型评估与优化
8. 部署与监控

## 阶段一：业务理解与问题定义
将业务需求转化为数据科学问题，决定后续所有步骤的方向。

| 问题类型     | 处理方式与重点关注                                         |
| :------- | :------------------------------------------------ |
| **分类问题** | 明确是二分类（如：欺诈与否）还是多分类（如：商品类别）。关注正负样本比例，决定是否需要不平衡处理。 |
| **回归问题** | 明确预测目标是连续值（如：房价、销量）。关注预测值的分布范围和长尾情况。              |
| **聚类问题** | 无监督学习，没有标签。明确聚类的业务意义（如：用户画像分群），以及评估标准（业务可解释性优先）。  |
| **时序问题** | 关注时间粒度（天/小时/秒），明确是预测未来单点还是序列，是否包含周期性/季节性。         |

## 阶段二：数据收集
获取原始数据，不同数据源的采集方式差异巨大。

| 数据类型 | 收集方式与注意点 |
| :- | :- |
| **结构化数据** | SQL数据库查询、CSV/Excel导入。注意表连接逻辑，避免数据泄露和笛卡尔积。 |
| **文本数据** | API爬虫、日志提取。注意编码格式（UTF-8等），去除HTML标签和不可见字符。 |
| **图像数据** | 开源数据集下载、摄像头采集。注意图片分辨率统一、存储路径规划。 |
| **流数据** | Kafka、Flume实时接入。关注吞吐量、断点续传和水位线。 |

## 阶段三：数据清洗与预处理
**垃圾进，垃圾出**，这是耗时最长但最关键的一步。
### 1. 缺失值处理
| 问题场景        | 处理方式                                   |
| :---------- | :------------------------------------- |
| **结构化/数值型** | 均值/中位数填充；预测模型填充（如KNN或随机森林填充）；或视为单独类别。  |
| **结构化/类别型** | 众数填充；或填充为“Unknown”/“缺失”作为一个新类别。        |
| **时序数据**    | 前向填充、后向填充、线性插值——**切忌用全局均值填充**，会破坏时间趋势。 |
| **文本数据**    | 删除空文档；或填充占位符（如`[MISSING]`）。            |
### 2. 异常值处理
| 问题场景 | 处理方式 |
| :- | :- |
| **回归/聚类** | 对异常敏感：使用IQR（四分位距）截断、对数变换压缩长尾、或删除。 |
| **分类（树模型）** | 树模型对异常值鲁棒，通常**不需要**特殊处理。 |
| **欺诈检测** | 异常值本身就是目标！不能删除，需单独提取并重点标记。 |

### 3. 数据标准化/归一化

| 问题场景                          | 处理方式                                              |
| :---------------------------- | :------------------------------------------------ |
| **距离类模型** (KNN, SVM, K-Means) | 必须做**Z-score标准化** 或 **Min-Max归一化**，否则量纲大的特征会主导距离。 |
| **梯度下降类** (神经网络, 逻辑回归)        | 必须标准化，加速收敛。                                       |
| **树模型** (随机森林, XGBoost)       | **不需要**标准化，树模型基于特征分裂，对尺度不敏感。                      |

## 阶段四：探索性数据分析 (EDA)
在建模前“摸底”数据，发现隐藏规律。

| 数据类型 | EDA 常用方法 |
| :- | :- |
| **结构化数据** | 特征分布直方图；特征与标签的相关性热力图；箱线图查看类别与数值的关系。 |
| **时序数据** | 折线图观察趋势；STL分解提取趋势和季节性；自相关(ACF)和偏自相关(PACF)图。 |
| **文本数据** | 词频统计柱状图；词云；文档长度分布图。 |
| **图像数据** | 随机抽样可视化；RGB通道分布；宽高比散点图。 |

## 阶段五：特征工程
**决定了模型的上限**。不同问题的特征构造逻辑完全不同。

| 问题/数据类型 | 特征工程核心技巧 |
| :- | :- |
| **结构化-分类问题** | 目标编码；WOE编码；特征交叉（如：年龄×收入）。 |
| **结构化-回归问题** | 对偏态目标值做对数变换；多项式特征扩展。 |
| **时序问题** | **极其重要！** 滞后特征（Shift）；滑动窗口统计（过去7天均值/最大值/方差）；时间提取（年/月/日/星期几/是否节假日）。 |
| **文本问题** | 传统：TF-IDF、CountVectorizer；<br>深度：Word2Vec/BERT词嵌入；<br>统计特征：文档长度、情感极性得分、标点符号数量。 |
| **图像问题** | 传统：SIFT/HOG边缘特征；<br>深度：数据增强（旋转、裁剪、加噪）、预训练模型提取特征向量。 |
| **聚类问题** | 降维特征提取（PCA、t-SNE、UMAP）；去除共线性特征，防止某些维度过度影响距离度量。 |

## 阶段六：模型建立与训练
选择合适的算法，不同问题的适用模型大相径庭。

| 问题类型        | 推荐模型与训练技巧                                                                                        |
| :---------- | :----------------------------------------------------------------------------------------------- |
| **结构化-二分类** | 基线：逻辑回归；<br>进阶：LightGBM / XGBoost（速度快、精度高）。                                                      |
| **结构化-多分类** | 随机森林；或使用 One-vs-Rest 策略的二分类器。                                                                    |
| **结构化-回归**  | 岭回归/Lasso；LightGBM Regressor。                                                                    |
| **时序预测**    | 统计学：ARIMA / Prophet；<br>树模型：LightGBM + 时序特征工程；<br>深度学习：LSTM / TimesNet。**注意：验证集必须按时间切割，不能随机打乱！** |
| **文本问题**    | 浅层：FastText；<br>深度：TextCNN / RNN；<br>前沿：BERT / RoBERTa 微调。                                       |
| **图像问题**    | 经典：ResNet / EfficientNet；<br>检测：YOLO / Faster R-CNN；<br>分割：U-Net。                                |
| **聚类问题**    | 基础：K-Means（需先定K值）；<br>密度：DBSCAN（处理不规则形状）；<br>层次：Agglomerative。                                   |

## 阶段七：模型评估与优化
避免过拟合，选择最符合业务诉求的模型。

| 问题类型 | 关键评估指标 | 调优方向 |
| :- | :- | :- |
| **分类 (均衡)** | 准确率 | 超参数搜索 |
| **分类 (不均衡)** | **F1-Score, AUC-ROC, 精确率, 召回率** | 调整类别权重；过采样(SMOTE)/欠采样；调整分类阈值。 |
| **回归** | RMSE, MAE, R² | 如果异常值多，关注MAE；如果大误差惩罚重，关注RMSE。 |
| **聚类** | 轮廓系数, 戴维斯-布尔丁指数 | 肘部法则选K；特征降维去噪。 |
| **时序** | MAPE, WAPE, RMSE | 滚动交叉验证；调整滑动窗口大小。 |


## 阶段八：部署与监控
模型上线不是终点，而是新的起点。

| 监控维度 | 处理方式与应对策略 |
| :- | :- |
| **数据漂移** | 监控线上特征分布与训练集的KS距离。若分布变化大，需重新训练模型。 |
| **概念漂移** | 业务逻辑变化导致原特征失效（如疫情改变了消费习惯）。需引入新特征或重新定义问题。 |
| **线上延迟** | 图像/大文本模型推理慢：考虑模型蒸馏、量化（INT8）、裁剪或转为ONNX/TensorRT加速。 |
| **A/B测试** | 新模型上线前，分流小部分流量进行A/B测试，对比业务核心指标（如转化率、GMV）再决定全量上线。 |


### 💡 核心避坑总结
1. **数据泄露**：在做特征工程（如标准化、目标编码）和划分数据集时，**必须只用训练集的统计量**去转换验证集和测试集，绝不能提前用到全局信息。
2. **时序不能随机切分**：时序数据的验证集必须在训练集时间之后，否则相当于“用未来预测过去”。
3. **不要盲目追求复杂模型**：如果特征工程做得好，简单的LightGBM往往能打败未经调参的深度学习模型，且可解释性更强、部署更容易。
