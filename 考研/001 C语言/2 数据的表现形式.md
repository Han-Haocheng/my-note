## 1. 二进制表示的数
#### 整型数的二进制表示
1. 整型数分为两种：有符号和无符号
	1. 有符号：0正1负
2. 占用字节数可为8位、16位或32位
3. 取值范围
    -------------------------------------------------------------------
	1. 字节数               有符号的                        无符号的
	2. 字节数         最小值       最大值          最小值       最大值
	3.    1               -128          +127              0              255
	4.    2             -32768       +32767           0            65535
	5.    3      -2147483648  +2147483647   0        4294967295
   ---------------------------------------------------------------------
4. 计算机内部存储的是 **补码**
5. 原码，反码，补码主要还是针对有符号二进制
6. 原码
	1. 0000 0001     +1
	2. 1000 0001      -1
7. 反码
	1. 正的  与原码相同
		1. 0000 0001
	2. 负的  除符号位不变，其他的都取反
		1. 1111 1110
8. 补码
	1. 正的  与原码相同
		1. 0000 0001
	2. 负的  在反码的基础上加一
		1. 1111 1111


#### 浮点数的二进制表示
1. 浮点数分成单精度浮点数（float）和双精度浮点数（double）
2. **单精度浮点数**占32位（4个字节），双精度浮点数占64位（8个字节）
3. 浮点型数据的一般表达式$$(-1)^{s}*2^{e}*m$$
	1. **e**是实际的阶码值，代表浮点数的取值范围。
	2. **m**是尾数，代表浮点数的精度。
	3. **s**是数符，代表浮点数的正负
4. 为统一浮点数的表现形式，执行754标准
5. ```
   符号位         指数位           尾数
   （1位）        （8位）         （23位）
   ----------------------------------------------------------
       S               E                        M
     |   |      |  || ... ||  |      |  ||  || ... ||  ||  |
   ----------------------------------------------------------
      31         30         23        22                 0
   ```
	1. S 代表符号位，占1位
	2. E 称为移码，占8位，E=127+e     （e是次方，即例如 3^2 ,e = 2）
	3. M 代表有效位数或称为“小数”，m2 = (1.M)2，即仅存小数。
6. **双精度浮点数**占64位，同理单精度。不考双精度
	1. S 1位
	2. E 11位，E = 1023 + e
	3. M 占52位

## 3. 常量和变量
#### 常量：值不能发生改变。
1. 整型常量
		1. 八进制整形  由数字 0 开头  034，065，057
		2. 十进制整形  如同数学中的数字  123，-78，90
		3. 十六进制整形  有 0X 或 0x 开头， 0x23,0Xff,0xac
	1. 长整型常量：后缀L、l,如：125L，56l等
	2. 无符号整型常量：后缀U或u，如：60u，256U等
	3. 无符号长整型常量：后缀LU，Lu，lU或lu,如：360LU
2. 实型常量
	1. 一个小数如：12.4，默认为double类型，只有12.4f 才是float类型
3. 字符常量：由一对单引号括起来的单个字符。如'A' , 'S' , '&' , '6' , 'の'
	1. 整数编码 -- ASCII码   一个字符占一个字节   '0' 的ASCII码是48 , 'A' 的ASCII码是65 , 'a' 的ASCII码是97
	2. 转义字符  '\n'换行符， '\a'响铃符， '\t'制表符
4. 字符串常量：用一对双括号将零个或多个字符序列括起来，如：“hello” , “This is a program”等
	1. C语言中，系统自动在字符串末尾加一个“串结束标志”：\0
	2. 如：字符串“world”，共5个字符，需占用6个字节                                                 其存储形式为： | w | o | r | l | d | \0 |
5. 符号常量：将常量定义为一个标识符
	1. 定义形式：#define <符号常量名> <常量>
		1. 如
		2. ```c
		   #define PI 3.1415926
		   #define TRUE 1
		   #define FALSE 0
		   ```

#### 变量：值可以改变。
标识符：
1. 开头的第一个字符必须是字母或下划线
2. 最长不能超过32个字符
3. 标识符区分大小写
4. 不能与关键字相同
5. 不能用用户自定义的函数或C语言库函数同名
6. 只能包含字母、数字、下划线

## 3. 标准输入输出函数
#### 输入函数
```c
scanf("格式控制字符",变量地址列表);
scanf("%d%d",&a,&b);//& 是取地址符，即取a、b所占空间的首地址
```
格式控制字符串，一般形式："%[<修饰符>]<格式字符>"
修饰字符主要类型
1. 字段宽度修饰符
	1. 用数字修饰输入字符占用的宽度（字符数）
	2. Eg：%3d -- 3个整型字符 , %4c -- 4个字符型字符 , %8lf -- 8 个字符 等
2. l和h
	1. L、l和H、h分别代表输入数据类型的长短
		1. l、L --> 可表示长整型，双精度浮点型
		2. H、h --> 可表示短整型数
		3. Eg：scanf("%10ld%hd%lf",&a,&b,&c);  //a按宽度为10的长整型数，b为短整型数，c为双精度浮点型数。
	2. 如果输入内容大于指定宽度，则会读取指定宽度长度，剩余保存在缓冲区。
3. 字符”`*`“
	1. 作用：跳过相应的数据，输入的数据不赋给变量。
```c
		int x=0,y=0,z=0;
		scanf("%d%*d%d",&x,&y,&z);//输入：11 22 33
		//结果 x = 11 , y = 33 , z = 0;
```

| 格式转换说明符 | 用法                                |
| ------- | --------------------------------- |
| %d或%i   | 输入十进制整数                           |
| %o      | 输入八进制整数                           |
| %x      | 输入十六进制整数                          |
| %c      | 输出一个字符，空白字符（包括空格、回车、制表符）也作为有效字符输入 |
| %s      | 输入字符串，遇到第一个空白字符是时结束               |
| %f或%e   | 输入一个float型的实数，以小数形式或指数形式输入均可      |
| %lf     | 输入一个double型的实数，以小数形式或指数形式输入均可     |
| %%      | 输入一个百分号%                          |


#### 输出函数
```c
printf("格式控制字符",输出项列表);
printf("%d%d",&a,&b);//& 是取地址符，即取a、b所占空间的首地址
```
修饰符：是可选的
1. 字段宽度修饰符
	1. 用数字修饰输出字符占用的宽度。
	2. 但实际输出长度可能大于指定宽度。
2. 对齐方式修饰符
	1. 默认输出方式为右对齐方式，在%后加上”-“，可是数据的输出方式改为左对齐
	2. Eg：%-3d,%-4c,%-5.2f等
		1. 即：%5d = [   42]
		2. %-5d = [42   ]
	3. 显示精度”.n“：若整数，则整数精度；若浮点数，则小数精度；若字符串，则从左侧截取的个数。
	4. C语言不支持同时指明进度和宽度
		1.如：scanf("5.2f",&a);是不对的。                                 

#### C语言为**字符**提供了专用的字符输入输出函数。

| 函数原理             | 函数功能                         |
| ---------------- | ---------------------------- |
| int getchar( );  | 将键盘读取的字符放入缓冲区，键盘输入的字符会显示在屏幕上 |
| int putchar(ch); | 将ch所对应的字符输出到屏幕               |
注意：与scanf( )输入函数不一样，字符输入函数将空格、制表符、换行符也作为字符接收
