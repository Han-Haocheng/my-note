### 极限与连续

**第22题**：设$x_{0}=0, x_{n}=\frac{1+2x_{n-1}}{1+x_{n-1}}(n=1,2,3,\cdots)$,则$\lim x_{n}=$\_\_\_\_\_\_.
答案：$\frac{1+\sqrt{ 5 }}{2}$
解析：显然$0 < x_n = \frac{2(1 + x_{n-1}) - 1}{1 + x_{n-1}} = 2 - \frac{1}{1 + x_{n-1}} < 2 \quad (n = 1, 2, 3, \dots),$即 $\{x_n\}$ 有界。
令$f(x) = 2 - \frac{1}{1 + x}$,
由 $f(x)$ 单调递增 $(x \geq 0)$, 则 $x_{n+1} = f(x_n) (n = 1, 2, 3, \dots)$ 单调。
因此 $\{x_n\}$ 收敛, 记 $\lim\limits_{n \to \infty} x_n = a$。
对递归方程 $x_n = \frac{1 + 2x_{n-1}}{1 + x_{n-1}}$ 两边取极限得 $a = \frac{1 + 2a}{1 + a}$, 即$a^2 - a - 1 = 0,$解得 $a = \frac{1 + \sqrt{5}}{2}$。

**第23题**：设$a_{0}>0, a_{n}=a_{n-1}(a_{n-1}+1)(n=1,2,\cdots)$,则$\lim a_{n}=$\_\_\_\_\_\_.
答案: $+ \infty$
分析:显然 $a_n > 0 \Rightarrow a_n = a_{n-1}(a_{n-1} + 1) > a_{n-1} \Rightarrow \{a_n\}$ 单调递增。
根据单调有界原则 $\lim\limits_{n \to \infty} a_n$ 存在或为 $+ \infty$。
若 $\lim\limits_{n \to \infty} a_n = a$ 为有限值 $\Rightarrow a > 0$。对 $a_n = a_{n-1}(a_{n-1} + 1)$ 两边，令 $n \to \infty$，有 $a = a(a + 1)$。
求得 $a = 0$，矛盾。因此 $\lim\limits_{n \to \infty} a_n = + \infty$。


### 导数与微分

**第35题**：设函数$f(x)$可导,$f^{\prime}(0)=1$,且对于任意的$x, h$,都有$f(x+h)=f(x)+f(h)+k x$,则$f^{\prime}(x)=$\_\_\_\_\_\_.
答案： $1 + x$
分析：因为 $f(x + h) = f(x) + f(h) + hx$，令 $h = 0$，可得 $f(0) = 0$。
那么  $\frac{f(x + h) - f(x)}{h} = \frac{f(h) - f(0)}{h} + x$
故$\lim\limits_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim\limits_{h \to 0} \frac{f(h) - f(0)}{h} + x,$
故$f'(x) = f'(0) + x = 1 + x.$

**第42题**：设函数$f(x)=\mathrm{e}^{x} \sin x$,则$f^{(n)}(x)=$\_\_\_\_\_\_.
答案： $(\sqrt{2})^n e^x \sin \left( x + n \cdot \frac{\pi}{4} \right)$
分析：$f'(x) = e^x (\sin x + \cos x) = \sqrt{2} e^x \sin \left( x + \frac{\pi}{4} \right),$
$f''(x) = \sqrt{2} e^x \left[ \sin \left( x + \frac{\pi}{4} \right) + \cos \left( x + \frac{\pi}{4} \right) \right] = (\sqrt{2})^2 e^x \sin \left( x + 2 \cdot \frac{\pi}{4} \right),$
假设 $f^{(n)}(x) = (\sqrt{2})^n e^x \sin \left( x + n \cdot \frac{\pi}{4} \right)$，则$f^{(n+1)}(x) = (\sqrt{2})^n e^x \left[ \sin \left( x + n \cdot \frac{\pi}{4} \right) + \cos \left( x + n \cdot \frac{\pi}{4} \right) \right]$
$= (\sqrt{2})^{n+1} e^x \sin \left[ x + (n+1) \cdot \frac{\pi}{4} \right],$
所以 $f^{(n)}(x) = (\sqrt{2})^n e^x \sin \left( x + n \cdot \frac{\pi}{4} \right).$

**第45题**：设$f(x)=\ln \frac{1-2 x}{1+3 x}, n \geqslant 2$,则$f^{(n)}(0)=$\_\_\_\_\_\_.
答案： $(-1)^{n-1}(n-1)![(-2)^n - 3^n]$

分析：
方法1  $f(x) = \ln(1-2x) - \ln(1+3x),$  $f^{(n)}(x) = (\ln(1-2x))^{(n)} - (\ln(1+3x))^{(n)},$

$f^{(n)}(0) = (-1)^{n-1}(n-1)![(-2)^n - 3^n].$

方法2  $\ln(1+t) = t - \frac{1}{2}t^2 + \cdots + \frac{(-1)^{n-1}}{n}t^n + o(t^n)$  
$= \sum_{k=1}^n \frac{(-1)^{k-1}}{k}t^k + o(t^n) \quad (t \to 0),$

则 $f(x) = \ln(1-2x) - \ln(1+3x) = \sum_{k=1}^n \frac{(-1)^{k-1}}{k}(-2x)^k - \sum_{k=1}^n \frac{(-1)^{k-1}}{k} (3x)^k + o(x^n)$  
$= \sum_{k=1}^n \frac{(-1)^{k-1}}{k} [(-2)^k - 3^k]x^k + o(x^n)$  
$\stackrel{\text{记}}{=} \sum_{k=1}^n a_k x^k + o(x^n) \quad (x \to 0),$

则  $f^{(n)}(0) = n!a_n = n! \frac{(-1)^{n-1}}{n} [(-2)^n - 3^n] = (-1)^{n-1}(n-1)![(-2)^n - 3^n].$

- **第90题**：设$\lim _{x \rightarrow 0} \frac{1}{\sin x-a x} \int_{b}^{x} \frac{t^{2}}{\sqrt{1+t^{4}}} \mathrm{~d} t=c$,则$a, b, c$满足的条件是\_\_\_\_\_\_.

答案： 0
分析： 方法 1 若知道以下事实：由 $\lim\limits_{x \to +\infty} f'(x) = A > 0 (< 0)$，则 $\lim\limits_{x \to +\infty} f(x) = +\infty$（$-\infty$），立即可得 $b = 0$。否则，若 $b > 0$（或 $b < 0$），则 $\lim\limits_{x \to +\infty} f(x) = +\infty$（$-\infty$），与 $f(x)$ 在 $(c, +\infty)$ 有界矛盾。

【评注】 可以用反证法证明 $b = 0$，不妨设 $b > 0$，取 $a$ 满足 $0 < a < b$，由 $\lim\limits_{x \to +\infty} f'(x) = b > a$，则存在 $x_0 > 0$。当 $x \geq x_0$ 时 $f'(x) > a$，在 $[x_0, x]$ 上用拉格朗日中值定理，
$f(x) - f(x_0) = f'(\xi)(x - x_0) > a(x - x_0) \quad (\xi \in (x_0, x)),$
即 $f(x) > a(x - x_0) + f(x_0)$，因
$\lim\limits_{x \to +\infty} [a(x - x_0) + f(x_0)] = +\infty,$
所以 $\lim\limits_{x \to +\infty} f(x) = +\infty$，从而 $f(x)$ 在 $(c, +\infty)$ 上无界，这与 $f(x)$ 在 $(c, +\infty)$ 上是有界函数矛盾。

方法 2 因 $f(x)$ 在 $(c, +\infty)$ 可导，有界。则 $\lim\limits_{x \to +\infty} \frac{f(x)}{x}$ 为无穷小乘有界量，有
$\lim\limits_{x \to +\infty} \frac{f(x)}{x} = 0,$
又
$\lim\limits_{x \to +\infty} \frac{f(x)}{x} = \lim\limits_{x \to +\infty} \frac{f'(x)}{x} = \lim\limits_{x \to +\infty} f'(x) = b \implies b = 0.$
