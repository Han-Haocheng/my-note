# 带通调制


![[Pasted image 20250915095801.png]]

**带通调制**：用**载波(carrier)** 进行调制，把基带信号的频率范围搬移到较高的频段，并*转换为模拟信号*
- 带通信号：经过载波调制后的信号，仅在一段频率范围内能够通过信道


## 方式

带通信号调制方式：调幅、调频、调相
### 调幅
调幅AM：即载波的振幅随基带数字信号而变化
- 举例：0 或 1 分别对应于无 载波或有载波输出。
### 调频

调频FM：即载波的频率随基带数字信号而变化 
- 举例：0 或 1 分别对应于频率 f1 或 f2。 
### 调相
调相PM：即载波的初始相位随基带数字信号而变化
- 举例：0 或 1 分别对应于 相位 0 度或 180 度

### 正交振幅调制

正交振幅调制 QAM (Quadrature Amplitude Modulation)：更为复杂的多元制的振幅相位混合调 制方法
