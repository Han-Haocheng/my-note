# IO 端口

IO 端口：IO 接口中的寄存器

## 分类

根据端口传输的信息分类：端口可分为数据端口，状态端口和控制端口。
- *数据端口*：用来保存 CPU 与外设之间传送的数据，对输入/输出数据起缓冲作用的数据寄存器。
- *状态端口*：用来存放外设或者接口部件本身状态的寄存器。
- *控制端口*：用来存放 CPU 发往外设的控制命令的控制寄存器。CPU 通过控制端口来设定 IO 接口的工作方式

## 编址

IO 端口地址：通过地址线选择对应 IO 端口的寄存器地址

### 统一编址

**统一编址**：IO 端口和存储单元构成一个统一的地址空间。
- 优点：访问内存的指令同样都可以用于访问 IO 端口，无需专门的 IO 指令，简化了指令系统的设计
- 缺点：占用存储器地址空间，减少内存地址的可用范围

### 独立编址

**独立编址**：在独立编址的方式中，建立了两个地址空间，一个为内存地址空间，一个为 IO 地址空间。内存地址空间与 IO 地址空间是相对独立的，通过控制总线来确定 CPU 到底要访问内存还是 IO 端口。
- 优点：不占用内存空间，IO 端口地址线根数少，译码电路简单，专用的输入输出指令便于理解和检查
- 缺点：需要专用 I/O 指令，增加了指令系统的复杂性
