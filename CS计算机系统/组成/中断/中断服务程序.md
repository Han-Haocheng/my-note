# 中断服务程序

中断服务程序：处理中断的程序
- 中断向量：中断服务程序的入口地址
- 中断向量地址：中断向量的地址

## 功能


- 保护现场：PUSH
- 其他服务程序：视不同请求源而定
- 恢复现场：POP
- 中断返回：IRET

1. 保护现场
	- 中断隐指令完成：保存程序断点
	- 中断服务程序完成：保存寄存器内容，进栈指令，多重中断下还会保存屏蔽字
2. 中断服务：对不同的 IO 设备具有不同内容的设备服务，多重中断下会开中断
3. 恢复现场：将保存的数据恢复，多重中断下会提前关中断
4. 中断返回：开中断后，发送中断返回指令

## 中断向量

- 硬件向量法：由硬件产生向量地址，再由向量地址找到入口地址
	- 类似设备编码器
- 由软件产生
