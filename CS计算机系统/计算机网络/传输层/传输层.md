# 传输层

![[Pasted image 20260620152921.png]]

 运输层 transport layer：通过应用进程间的交互来完成特定网络应用，应用进程间通信和交互的规则，为运行在不同 Host 上的*应用进程*提供了一种逻辑通信机制


- 发送方：将应用递交的消息分成一个或多个 Segment，并向下传给网络层
- 接收方：将接收的 Segment 组成消息，并向上交给应用层
- 包含协议：TCP、UDP
- 特点：位于网络层之上、依赖网络层服务、对网络层服务进行增强

## 功能

 运输层：负责源-目的（端-端）进程之间完整报文传输
- 分段重组
- SAP 寻址：通过端口号，确保将完整报文提交给正确进程
- 连接控制
- 流量控制
- 差错控制

## 协议


### TCP

 传输控制协议 TCP(Transmission Control Protocol)：提供面向连接的、可靠的数 据传输服务
- TCP协议：可靠、按序的交付服务，包含拥塞控制、流量控制、建立连接功能

  传输控制协议 TCP：报文段 segment

### UDP

 用户数据报协议 UDP(User Datagram Protocol)—提供无连接的、尽最大努力 (best-effort)的数据传输服务（不保证数据传输的可靠性）
- UDP 协议：不可靠的交付服务，基于尽力而为 Best-effort 的网络层，没有做扩展

  UDP：用户数据报 User Datagram
