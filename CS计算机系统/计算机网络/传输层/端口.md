# 端口

端口：是一个 16 位(16-bit)的整数,其取值范围是 0 到 65535


## 分类

| 类别   | 端口范围          | 说明                         |
| ---- | ------------- | -------------------------- |
| 熟知端口 | 0 ~ 1023      | 给最常用的应用层协议使用，如 HTTP、FTP 等。 |
| 登记端口 | 1024 ~ 49151  | 为没有熟知端口的应用服务使用             |
| 临时端口 | 49152 ~ 65535 | 客户进程运行时动态选择，通信结束后立即释放。     |



服务器端口号：IANA负责分配登记
- 全球通用端口号0~1023
- 登记端口1024~49151

客户端端口号：通信结束后系统回收
- 短暂端口49152~65535

## 功能

### 应用进程之间通信
- 两个主机进行通信实际上就是两个主机中的应用进程互相通信;
- 应用进程之间的通信又称为端到端的通信;
- 传输层的一个很重要的功能就是复用和分用;
### 复用
- 复用:在发送方,多个应用进程的传输数据可以共享同一个传输层的通信通道。
### 分用
- 分用:在接收方,分析数据包中的端口号,利用其中的信息将数据正确交付到目标应用进程。
