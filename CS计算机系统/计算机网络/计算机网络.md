# 计算机网络

计算机网络：利用*通信线路*将地理上分散的、具有独立功能的*计算机系统*和*通信设备*按*不同的形式*连接起来，以功能完善的*网络软件*及*协议*实现*资源共享*和*信息传递*的系统。是由一些*通用的、可编程*的并非专门用来实现某一特定目的*硬件*互连而成的系统，这些可编程的硬件能够用来传送多种不同类型的数据，并能支持广泛的和日益增长的应用
- 可编程硬件：含有 CPU 的硬件

## 网络分类

### 按照网络的作用范围进行分类

| 类别           | 作用范围      |                    |
| ------------ | --------- | ------------------ |
| 互联网（因特网）     | 全世界       | 一个世界范围的计算机网络       |
| 广域网（远程网） WAN | 几十到几千公里   | 可以跨越城市、国家甚至全球（互联网） |
| 城域网 MAN      | 5 ~ 50 km | 一般在一个城市或大都市区域内     |
| 局域网 LAN      | 1 km      | 通常在一个建筑物或校园内       |
| 个人区域网 PAN    | 10 m      | 通常在个人设备之间通信        |


### 按照网络的使用者进行分类

| 类别  | 含义                               |
| --- | -------------------------------- |
| 公用网 | 这是指电信公司（国有或私有）出资建造的大型网络          |
| 专用网 | 这是某个部门为满足本单位的特殊业务工作的需要而建<br>造的网络 |


## 组成

### 从主要构件来看
从主要构件来看，包括硬件、软件和协议
- 硬件：网络运行的基础
- 软件：网络模块和应用
- 协议：网络中设备通信的“规则和语言”

### 从功能组成来看
从功能组成来看，包括通信子网和资源子网
- 通信子网：传输比特，把一个设备数据传到另一个设备
- 资源子网：提供服务，包括访问网页，下载文件等
### 从工作方式来看

从工作方式来看，包括边缘部分和核心部分
- 边缘部分：用户直接使用网络的部分
- 核心部分：网络中专门用于数据转发的部分


## 性能指标

### 速率

#计算机/网络/性能指标 速率（数据率、比特率）：数据的传送速率，单位时间内参数的比特数。
- 通常为额定速率或标称速率，并非实际速率

#计算机/网络/性能指标/单位 速率单位（换算 1000）：bit/s、Kbit/s、Mbit/s、Gbit/s

### 带宽

#计算机/网络/性能指标 带宽 bandwidth：带宽越宽，最高数据率越高
- 包含频域带宽和时域带宽

![[Pasted image 20250901103626.png]]


#计算机/网络/性能指标/带宽 频域带宽：某个信号具有的<font color="#c 0504 d">频带宽度</font>
- 信道的带宽（通频带）：某信道允许通过的信号频带范围

#计算机/网络/性能指标/计算 频域带宽 $=F_{max}-F_{min}$

#计算机/网络/性能指标/单位 频域带宽：Hz


#计算机/网络/性能指标/带宽 时域带宽：网络中某通道传送数据的能力，表示在单位时间内网络中的某信道所能通过的“<font color="#c 0504 d">最高数据率</font>”

#计算机/网络/性能指标/单位 时域带宽(换算 $10^{3}$)：bit/s

### 时延


![[Pasted image 20250901110124.png]]

#计算机/网络/性能指标 时延 delay（latency）：数据（一个报文或分组，甚至比特）从网络（或链路）的一端传送到另一端所需的时间
- 一般说来，小时延的网络要优于大时延的网络
- 在某些情况下，一个低速率、小时延的网络很可能要优于一个高速率但大时延的网络

#计算机/网络/性能指标/计算 时延 $d=d_{proc}+d_{queue}+d_{trans}+d_{prop}$

#### 处理时延

#计算机/网络/性能指标/时延 处理时延 $d_{proc}$ (nodal processing delay)：主机或路由器在收到分组时要花费一定的时间进行处理
- 特点：差错检测、确定输出链路、通常小于毫秒
- 例如：分析分组的首部、从分组中提取数据部分、进行差错检验或查找适当的路由等


#### 排队时延
#计算机/网络/性能指标/时延 排队时延 $d_{queue}$ (queueing delay)：分组在路由器输入输出队列中排队等待处理和转发所经理的时延
- 等待输出链路可用
- 取决于路由器的拥塞程度

#计算机/网络/性能指标/计算 流量强度 traffic intensity $=\frac{La}{R}$
- 链路宽带 R（bps）
- 分组长度 L（bits）
- 平均分组到达速率 a

$\frac{La}{R}\sim 0$：平均排队延迟小
$\frac{La}{R}\sim 1$：平均排队延迟大

#### 发送时延

#计算机/网络/性能指标/时延 发送时延 $d_{trans}$ (transmission delay)：从第一个 bit 到最后一个 bit 所需要的时间，和发送器相关

#计算机/网络/性能指标/单位 发送时延：s

#计算机/网络/性能指标/计算 发送时延 $d_{trans}=\frac{L}{R}$
- 分组长度 $L$ (bits)
- 链路带宽 $R$ (bps)

#### 传播时延

#计算机/网络/性能指标/时延 传播时延 $d_{prop}$ (propagation delay)：电磁波在信道中传播一定的距离需要花费的时间，和信道相关
- 常用信道传播速率：空间 $3.0\times10^8m$、同轴电缆 $2.3\times10^8m$、光纤 $2.0\times10^8m$

#计算机/网络/性能指标/单位 传播时延：s

#计算机/网络/性能指标/计算 传播时延 $d_{trans}=\frac{d}{s}$
- 物理链路长度 d（m）
- 信号传播速度 s（m/s）
