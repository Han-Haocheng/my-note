##[[运输层]]
#### TCP

#计算机/网络/协议 传输控制协议 TCP(Transmission Control Protocol)：提供面向连接的、可靠的数 据传输服务

#计算机/网络/传输单元  传输控制协议 TCP：报文段 segment

#### UDP

#计算机/网络/协议 用户数据报协议 UDP(User Datagram Protocol)—提供无连接的、尽最大努力 (best-effort)的数据传输服务（不保证数据传输的可靠性）

#计算机/网络/传输单元  UDP：用户数据报 User Datagram

### 网络层

#计算机/网络/结构 #计算机/网络/网络层 网络层 network layer：为分组交换网上的不同主机提供通信服务，封装成分组或包

#计算机/网络/协议 网络层支持协议：IP、路由协议

#计算机/网络/传输单元 网络层 ：IP 数据报、数据报、分组

#计算机/网络/结构/功能 网络层：源-目的数据分组、逻辑寻址、路由、分组转发
- 源主机-目的主机数据分组 packet：可能穿过多个网络
- 逻辑寻址 Logical addressing：全局唯一逻辑地址，确保数据分组被送达目的主机
- 路由 Routing：路径选择，互联网络，路由分组到最终目的主机
- 分组转发

### 数据链路层

#计算机/网络/结构 #计算机/网络/数据链路层 数据链路层(data link layer)：负责两个相邻结点之间的数据传输

#计算机/网络/传输单元 #计算机/网络/数据链路层 数据链路层：组装成帧(framing)、帧(frame)

#计算机/网络/数据链路层 数据链路层：结点-结点数据传输、组帧、物理寻址、流量控制、差错控制、接入访问控制
- 结点-结点 node-to-node 数据传输
- 组装成帧 Framing
- 物理寻址 Physical addressing：在帧头增加发送端、接收端的物理地址，标识数据帧的发送端、接收端
- 流量控制 Flow control：避免淹没接收端
- 差错控制 Error control：检测并重传损坏或丢失帧，避免重复帧
- 接入访问控制 Access control：在任一给定时刻决定哪个设备拥有链路控制使用权

### 物理层

#计算机/网络/结构 #计算机/网络/物理层 物理层 physical layer：确定连接电缆的插头应当有多少根引脚，以及各引脚应如何连接，实现比特(0 或 1)的传输

#计算机/网络/传输单元 物理层：比特

#计算机/网络/结构/功能 物理层：确定与传输媒体的<font color="#c 0504 d">接口</font>特性、比特编码、数据率、比特同步，传输模式
