# IPv 4 协议


IPv 4 协议：第四代网际协议

## 结构


![[Pasted image 20251027090443.png]]

- IP 数据报由首部和数据两部分组成
- 首部的前一部分是固定长度，共 20 字节，是所有 IP 数据报必须具有的。
- 可选字段，其长度是可变的

| 字段                           | 字段长度  | 含义                                                                             |
| ---------------------------- | ----- | ------------------------------------------------------------------------------ |
| *版本*                         | 4 位   | 指 IP 协议的版本<br>目前的 IP 协议版本号为 4 (即 IPv 4)                                        |
| *首部长度*                       | 4 位   | 可表示的最大数值，是 15 个单位(一个单位为 4 字节)<br>因此 IP 的首部长度的最大值是 60 字节                        |
| *区分服务*<br>DiffServ           | 8 位   | 用来获得更好的服务，在一般的情况下都不使用这个字段                                                      |
| *总长度*                        | 16 位  | 首部和数据之和的长度，单位*字节*<br>因此数据报的最大长度为 *65535 字节*<br>总长度必须不超过[[最大传送单元]] MTU          |
| *标识* <br>identification      | 16 位  | 计数器，用来产生 IP 数据报的标识                                                             |
| *标志* flag                    | 3 位   | MF（More Flag）：位 0，=1 表示后面还有分片，=0 表示最后一个分片<br>DF（Dont Flag）： 位 1，只有当 =0 时才允许分片。 |
| *片偏移* offset                 | 13 位  | 较长的分组在分片后，某片在原分组中的相对位置<br>以 8 个字节为偏移单位                                         |
| *生存时间* TTL<br>(Time To Live) | 8 位   | 指示数据报在网络中可通过的路由器数的最大值                                                          |
| *协议*                         | 8 位   | 指出此数据报携带的数据使用何种协议，以便目的主机的 IP 层将数据部分上交给那个处理过程                                   |
| *首部检验和*                      | 16 位  | 只检验数据报的首部，不检验数据部分<br>这里不采用 CRC 检验码而采用简单的计算方法                                   |
| *源地址*                        | 32 位  |                                                                                |
| *目的地址*                       |  32 位 |                                                                                |

## 流程

### 分片流程

发送方
1. 从传输层服务获取发送数据
2. 判断数据报是否超出数据链路层的MTU
3. 超出则按照 MTU 大小为 IP数据报的*数据部分*进行分片
4. 为每个数据分片添加一个 IP 数据报*首部*
5. 发送到数据链路层服务

接收方
1. 从数据链路层服务接收数据
2. 判断当前 IP 数据报是否是分片的
3. 连续接收多个 IP 片，并合并为 IP 数据报
4. 执行传输层服务
