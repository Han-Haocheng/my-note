# IP 组播
![[Pasted image 20260620111700.png]]

IP 组播：允许数据从一个源发送到多个目标，通常基于 UDP 协议进行传输


IGMP 的作用
- 设备可以通过 IGMP 协议加入组播组
- 路由节点可以根据 IGMP 协议判断改组播组中包含哪些成员
## 流程

### 组播地址转换为物理地址

IPv 4 组播 MAC 地址的固定前缀为 **`01-00-5E`**
- `01`：以太网 MAC 地址的第一字节最低位为 `1` 表示组播。
- `00-5E`：IANA 向 IEEE 申请的 OUI（组织唯一标识符）用于组播。
- `XX` 的最高位固定为 `0`，因此第四字节的范围是 `00` 到 `7F`。这留给组播地址的可变部分正好是 23 位。

取 IP 组播地址的**最后 23 位**（即第一字节的最后 7 位 + 第二字节 8 位 + 第三字节 8 位），将其直接填入 MAC 地址的最后 23 位中。
