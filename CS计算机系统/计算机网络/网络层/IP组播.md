# IP 组播
![[Pasted image 20260620111700.png]]

IP 组播：允许数据从一个源发送到多个目标，通常基于 UDP 协议进行传输


IGMP 的作用
- 设备可以通过 IGMP 协议加入组播组
- 路由节点可以根据 IGMP 协议判断改组播组中包含哪些成员
## 流程

### 组播地址转换为物理地址


取 IP 组播地址的**最后 23 位**（即第一字节的最后 7 位 + 第二字节 8 位 + 第三字节 8 位），将其直接填入 MAC 地址的最后 23 位中。
