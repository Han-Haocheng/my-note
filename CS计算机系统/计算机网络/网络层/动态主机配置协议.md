# 动态主机配置协议

动态主机配置协议DHCP：

## 流程

1. DHCP 发现
2. DHCP 提供
3. DHCP 请求
4. DHCP 确认
### DHCP 发现
DHCP发现 DHCP Discover：当一台设备(客户端)首次连接到网络时,它并没有有效的 IP 地址,所以它以 0.0.0.0 作为源 IP 地址,向网络发送一个广播消息
- 源 IP 0.0.0.0
- 目的 IP 255.255.255.255


### DHCP 提供
**DHCP 提供**DHCP Offer：DHCP 服务器收到 DHCP 发现消息后,会向客户端发送一个 *DHCP 提供消息*
### DHCP 请求
DHCP 请求DHCP Request:客户端收到 DHCP 提供后,如果接受服务器提供的 IP 地址和其他参数,就会发送一个 DHCP 请求消息


### DHCP 确认

DHCP 确认DHCP Acknowledge:DHCP 服务器在收到客户端的 DHCP 请求后,会向客户端发送一个 DHCP 确认消息
