
# 网络层
![[Pasted image 20251103083213.png]]

**网络层**：网络层负责找出数据包的最佳传输路径，保证它跨越多个不同网络，准确送达到对方

## 功能

### 路由选择

**路由选择**：通过路由协议计算最佳路径，确保数据包高效、可靠地传输
- [[路由算法]]
- [[软件定义网络]]


### 逻辑地址寻址

**逻辑地址寻址**：网络层为每台主机分配唯一的逻辑地址（如 IP 地址），使得网络中的每个设备能够被唯一识别

### 数据包转发

**数据包转发**：网络层负责将数据分割成数据包，按逻辑地址转发到下一跳节点，直到到达目的地


### 网络地址转换

网络地址转换 NAT（Network Address Translation）：一种用于在网络中转换 IP 地址的技术。它主要用于将内部网络(局域网,LAN)中的私有 IP 地址转换为公共网络(广域网,WAN)上的公共 IP 地址


私有 IP 地址是只能在局域网内部使用的,无法直接在互联网上通信。这些私有 IP 地址的范围包括以下几类:

A 类:10.0.0.0-10.255.255.255
B 类:172.16.0.0-172.31.255.255
C 类:192.168.0.0 -192.168.255.255

这些地址不能在互联网上路由,因此,需要通过 NAT 将这些私有地址转换为公共 IP 地址。

数据层面
- 路由器根据本路由器生成的转发表，把收到的分组从查找到的对应接口转发出去。
- 独立工作。
- 采用硬件进行转发，快。

控制层面
- 根据路由选择协议所用的路由算法计算路由，创建出本路由器的路由表，
- 许多路由器协同动作，
- 采用软件计算，慢。
