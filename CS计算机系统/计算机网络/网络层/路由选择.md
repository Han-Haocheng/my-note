# 路由选择


理想的路由算法：稳定、自适应、公平、最佳、计算简单、正确完整
- 最佳路由：不存在一种绝对的最佳路由算法，相对于某一种特定要求下得出的较为合理的选择

## 分类

路由算法分类：静态路由选择策略、动态路由选择策略
- 静态路由选择策略：非自适应路由选择，不能适应网络状态变化，简单开销小
- 动态路由选择策略：自适应路由选择，能较好适应网络状态变化，复杂开销大

## 分层路由选择

分层次的路由选择协议：采用自适应的（动态的）、分布式*路由选择协议*，把整个互联网划分为许多较小的*自治系统* AS，采用*分层*次的路由选择协议
- 层次：域间路由选择interdomain routing（自治系统之间路由选择）、域内路由选择intradomain routing（自治系统内部路由选择）
### 自治系统

自治系统 AS（Autonomous System）：是在单一技术管理下的许多网络、IP地址以及路由器，而这些路由器使用一种自治系统内部的路由选择协议和共同的度量
- 每一个 AS 对其他 AS 表现出的是一个单一的和一致的路由选择策略

### 路由选择协议
![[Pasted image 20251103095149.png]]

路由选择协议：内部网关协议 IGP 、外部网关协议 EGP 
- **内部网关协议** IGP（Interior Gateway Protocol）：在一个自治系统内部使用的路由选择协议，包含 [[路由信息协议|RIP]]、[[开放最短路径优先协议|OSPF]]
- **外部网关协议** EGP （External Gateway Protocol）：在不同自治系统之间进行路由选择时使用的协议。[[边界网关协议|BGP]]
