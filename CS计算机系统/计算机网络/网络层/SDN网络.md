# SDN 网络

SDN：是一种新型的网络架构理念，它通过将网络控制平面与数据转发平面分离，实现网络的集中管理和灵活控制。控制器通过统一的软件接口对整个网络进行管理
- 传统网络：网络设备同时承担控制和转发功能，网络控制分散在各个设备中，配置复杂且不灵活。
- SDN网络：将网络的控制功能集中到一个或多个控制器上，设备只负责简单的数据转发。。

| 特点   | 传统网络  | SDN 网络 |
| ---- | ----- | ------ |
| 网络功能 | 控制和转发 | 转发     |
| 控制位置 | 分散    | 集中     |
| 配置   | 复杂不灵活 | 简单     |
|      |       |        |


主要特征
1. 网络开放可编程
2. 控制平面与数据平面分离
3. 逻辑上的集中管理
