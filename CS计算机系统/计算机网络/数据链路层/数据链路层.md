# 数据链路层

数据链路层(data link layer)：负责两个相邻结点之间的数据传输
- 传输单元：帧frame


## 功能

- 结点-结点 node-to-node 数据传输
- 组装成帧 Framing

- 物理寻址 Physical addressing：在帧头增加发送端、接收端的物理地址，标识数据帧的发送端、接收端
- 流量控制 Flow control：避免淹没接收端
- 差错控制 Error control：检测并重传损坏或丢失帧，避免重复帧
- 接入访问控制 Access control：在任一给定时刻决定哪个设备拥有链路控制使用权




### 为网络层提供服务


- 组帧：帧定界、帧同步与透明传输
- 可靠交付和流量控制：保证数据成功传输到接收方,控制发送方的发送速率
- 差错控制：添加校验位,让接收方能够对数据进行检错或纠错
- 介质访问控制：协调多个设备对信道的访问,避免冲突

## 类型
### 点对点信道
点对点信道：这种信道使用一对一的点对点通信方式
### 广播信道
广播信道：这种信道使用一对多的广播通信方式，因此过程比较复杂。广播信道上连接的主机很多，因此必须使用专用的共享信道协议来协调这些主机的数据发送。
