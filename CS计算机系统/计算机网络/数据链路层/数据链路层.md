






# 数据链路层


![[Pasted image 20250922102035.png]]

数据链路层(data link layer)：负责两个相邻结点之间的数据传输，属于计算机网络的低层
- 传输单元：帧frame



![[Pasted image 20250922095454.png]]

H 1 到 H 2 的通信可以看成由四段不同的链路层通信组 成，即：H 1→R 1，R 1→R 2，R 2→R 3 和 R 3→H 2。这四段不同的链路层可能采用不同的数据链 路层协议


## 功能

- 结点-结点 node-to-node 数据传输
- [[封装成帧|组帧Framing]]：帧定界、帧同步与透明传输
- 物理寻址 Physical addressing：在帧头增加发送端、接收端的物理地址，标识数据帧的发送端、接收端
- [[流量控制|流量控制Flow control]]：控制发送方的发送速率
- [[差错控制|差错控制Error control]]
- [[可靠传输]]：保证数据成功传输到接收方
- [[介质访问控制]]：协调多个设备对信道的访问，避免冲突
- 接入访问控制 Access control：在任一给定时刻决定哪个设备拥有链路控制使用权

### 为网络层提供服务

为网络层提供服务：数据链路层通常可为网络层提供如下服务
- 无确认的无连接服务：发就完了，不确认也不重传，丢了就丢了
- 有确认的无连接服务：我虽然不提前打招呼（不建连接），但你得告诉我你收到了（确认），不然我可能重发
- 有确认的有连接服务：我们先握个手（建立连接），你每收到一份数据都告诉我（确认），万一中间断了我们还能恢复
- ~~无确认的有连接服务~~：X 不存在，既然建立了连接，却不确认数据的接收，既没有可靠性，又增加了开销和复杂度

### 点对点信道

点对点信道：这种信道使用一对一的点对点通信方式

### 广播信道

![[Pasted image 20260609164338.png]]

广播信道：这种信道使用一对多的广播通信方式，因此过程比较复杂。广播信道上连接的主机很多，因此必须使用专用的共享信道协议来协调这些主机的数据发送。
