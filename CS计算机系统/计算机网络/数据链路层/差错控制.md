# 差错控制


**差错控制**：检测并重传损坏或丢失帧，避免重复帧，添加校验位，让接收方能够对数据进行检错或纠错


## 编码

检错编码：奇偶校验码、循环冗余校验码 CPC

纠错编码：海明码

### 奇偶校验码

![[Pasted image 20260607113335.png]]

奇偶校验法：包括奇校验和偶校验，在数据最后增添一个 bit，让整个数据为 1 的数量为奇数（偶数）
- 优点：简单
- 缺点：只能检测单个位错误、没有纠错能力

### 循环冗余校验码

循环冗余校验码CRC：通过要传输的数据和生成多项式，生成 CRC 校验码，将 CRC 校验码放在数据末尾传输
- 生成多项式：是一个二进制数，通常用一个多项式表示，其中每个位对应一个幂次。CRC 使用一个生成多项式来进行校验码的生成和验证。
- 例如，一个常见的生成多项式 $x^3 + x + 1$，代表二进制数 1011
- 生成多项式由通信双方事先规定。

生成
1. 将生成多项式转换为对应的二进制(CRC 校验码的位数 n=生成多项式对应二进制的位数-1)
2. 在要传输的数据末尾加 n 个 0
3. 进行除法运算


### 海明码

海明码
- 校验位的位置：是按照特定的规则进行的,通常是在 2 的幂次方位置上
- 每个校验位：
- 接收方进行差错检测

- 如果两位出错,海明码可以检错,无法纠错
- 如果三位出错,海明码不能检错,也不能纠错

- 校验位 1（二进制 00001）负责的位：3、5、7、9、11、13、15、17  
- 校验位 2（二进制 00010）负责的位：3、6、7、10、11、14、15

- 校验位 8（二进制 01000）负责的位：9、10、11、12、13、14、15  
- 校验位 16（二进制 10000）负责的位：17  

之后对某校验位负责的所有位数做一个偶校验。

验证：对对应位进行异或，如果全为 0，代表传输数据没问题。如果只有一位发生错误的话，那么错误的这一位的位置是将上述的异或结果倒过来。

出错的位置为：00111
- 校验位 1：3、5、7、9、11、13、15、17；$0 \oplus 1 \oplus 0 \oplus 0 \oplus 0 \oplus 0 \oplus 1 \oplus 1 \oplus 0 \oplus 0 = 1$
- 校验位 2：3、6、7、10、11、14、15；$1 \oplus 1 \oplus 1 \oplus 0 \oplus 1 \oplus 0 \oplus 0 \oplus 1 = 1$
- 校验位 4：5、6、7、12、13、14、15；$0 \oplus 0 \oplus 1 \oplus 0 \oplus 0 \oplus 1 \oplus 0 \oplus 1 = 1$
- 校验位 8：9、10、11、12、13、14、15；$1 \oplus 0 \oplus 1 \oplus 0 \oplus 0 \oplus 1 \oplus 0 \oplus 1 = 0$
- 校验位 16：17 $0 \oplus 0 = 0$


码距：是指两个编码之间不同位的数量，或者说是两个编码之间的差异程度
- 海明距：对于海明码，两个码字之间不同的位数
- 如果要检测 e 个错误，编码系统码距应该满足：$D \ge e + 1$
- 如果要纠正 t 个错误，编码系统码距应该满足：$D \ge 2t + 1$
