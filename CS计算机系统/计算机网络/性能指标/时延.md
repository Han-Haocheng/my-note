# 时延


![[Pasted image 20250901110124.png]]

 时延 delay（latency）：数据（一个报文或分组，甚至比特）从网络（或链路）的一端传送到另一端所需的时间
- 一般说来，小时延的网络要优于大时延的网络
- 在某些情况下，一个低速率、小时延的网络很可能要优于一个高速率但大时延的网络


## 组成
 公式 $d=d_{proc}+d_{queue}+d_{trans}+d_{prop}$

### 处理时延

 处理时延 $d_{proc}$ (nodal processing delay)：主机或路由器在收到分组时要花费一定的时间进行处理
- 特点：差错检测、确定输出链路、通常小于毫秒
- 例如：分析分组的首部、从分组中提取数据部分、进行差错检验或查找适当的路由等


### 排队时延
 排队时延 $d_{queue}$ (queueing delay)：分组在路由器输入输出队列中排队等待处理和转发所经理的时延
- 等待输出链路可用
- 取决于路由器的拥塞程度

 公式：流量强度 traffic intensity $=\frac{La}{R}$
- 链路宽带 R（bps）
- 分组长度 L（bits）
- 平均分组到达速率 a

$\frac{La}{R}\sim 0$：平均排队延迟小
$\frac{La}{R}\sim 1$：平均排队延迟大

### 发送时延

发送时延 $d_{trans}$ (transmission delay)：从第一个 bit 到最后一个 bit 所需要的时间，和发送器相关
- 单位：s

公式 $d_{trans}=\frac{L}{R}$
- 分组长度 $L$ (bits)
- 链路带宽 $R$ (bps)

### 传播时延

 传播时延 $d_{prop}$ (propagation delay)：电磁波在信道中传播一定的距离需要花费的时间，和信道相关
- 常用信道传播速率：空间 $3.0\times10^8m$、同轴电缆 $2.3\times10^8m$、光纤 $2.0\times10^8m$
 - 单位：s

 公式：传播时延 $d_{trans}=\frac{d}{s}$
- 物理链路长度 d（m）
- 信号传播速度 s（m/s）
