# 软件定义网络

![[Pasted image 20251020085132.png]]


**软件定义网络 SDN** (Software Defined Network)：是一种新型的网络架构理念，它通过将网络控制平面与数据转发平面分离，实现网络的集中管理和灵活控制。控制器通过统一的软件接口对整个网络进行管理


主要特征
1. 网络开放可编程
2. 控制平面与数据平面分离
3. 逻辑上的集中管理


对比

| 特点   | 传统网络  | SDN 网络 |
| ---- | ----- | ------ |
| 网络功能 | 控制和转发 | 转发     |
| 控制位置 | 分散    | 集中     |
| 配置   | 复杂不灵活 | 简单灵活   |
