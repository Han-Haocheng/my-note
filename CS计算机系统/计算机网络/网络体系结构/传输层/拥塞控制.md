# 拥塞控制

拥塞Congestion：太多发送主机发送了太多数据或发送速度太快，以至于网络无法处理
## 表现

表现：分组丢失、分组延迟过大
- 分组丢失：路由器缓存溢出
- 分组延迟过大：在路由器缓存中排队


## 方式
### 端到端的拥塞控制

端到端的拥塞控制：网络层不需要显式提供支持。端系统通过观察loss，delay等网络行为判断是否发送拥塞

### 网络辅助的拥塞控制

网络辅助的拥塞控制：路由器向发送方显示反馈网络拥塞信息。简单的拥塞指示。指示发送方应采取何种速率

## 成因

设
- 输入数据$\lambda_{in}$
- 输出数据$\lambda_{out}$
- 路由器带宽$C$
- 包含输入和重传的数据$\lambda'_{in}$

## 过程

![[2025-12-23_202834.svg]]

发送端限制发送速率：`LastByteSent-LastByteAcked <= 拥塞窗口cwnd`，$rate\simeq \frac{拥塞窗口cwnd}{RTT}Bytes/sec$
- 拥塞窗口cwnd：动态调整以改变发送速率，反应所感知到的网络拥塞
- 感知网络拥塞：设定Loss事件为timeout或3个重复ACK。loss事件发生时，发送端降低发送速率
- 调整发送速率方式：加性增乘性减AIMD、慢启动SS


### 慢启动
**慢启动SS**：TCP建立时拥塞窗口cwnd为1，可用宽带远高于初始速率，ConWin开始*指数性增长*
- ss阈值：到达此阈值开始AIMD

### 加性增

| 策略名称 | 增加方式 | 减少方式 | 公式表示（Δt内）                    |
| ---- | ---- | ---- | ---------------------------- |
| AIMD | 加性增  | 乘性减  | cwnd += α; cwnd *= β (β≈0.5) |
| AIAD | 加性增  | 加性减  | cwnd += α; cwnd -= γ         |
| MIAD | 乘性增  | 加性减  | cwnd *= δ; cwnd -= γ         |
| MIMD | 乘性增  | 乘性减  | cwnd /= δ; cwnd /= β         |

**加性增-乘性减AIMD**（Additive Increase-Mulitplicative Decrease）：逐渐增加发送速率，谨慎探测可用宽带，直到发生loss事件
- 加性增Additive Increase：每个RTT将拥塞窗口cwnd增大一个MSS
- 乘性减Mulitplicative Decrease：发生loss事件后将拥塞窗口cwnd减半

**Threshold变量**：当拥塞窗口cwnd达到丢失事件前1/2时切换为线性增长
- 实现方式：Loss事件发生，设置变量Threshold为事件发生前拥塞窗口cwnd值的1/2


### 事件处理

**丢失事件处理Loss**：两种引发条件处理方式不同
- 收到3个重复ACKs：SS阈值拥塞窗口cwnd变为一半
- 超时事件Timeout：拥塞窗口cwnd直接设为1 MSS，然后进入慢开始流程，到达threshold后线性增长

## 实现

### ATM ABR拥塞控制

![[Pasted image 20251110154919.png]]

ABR（available bit rate）：弹性服务，如果发送方路径underloaded，则使用可用带宽。如果发送方路径拥塞，将发送速率降到最低保障速率。

RM（resource management）cells：发送方发送，交换机设置RM cell位网络辅助，有接收方返回给发送方
- RMcell位：rate不许增长NI，拥塞指示CI

- 在RM cell中有显式的速率（ER）字段(2Byte)：拥塞的交换机可以将ER置为更低的值发送方获知路径所能支持的最小速率。
- 数据cell中的EFCI位：拥塞的交换机将其设为1，如果RM cell前面的data cell的EFCI位被设为1，那么发送方在返回的RMcell中置CI位
### TCP拥塞控制

```c
Th = ?
拥塞窗口cwnd = 1 MSS

BEGIN:
	// 慢启动或指数增长
	While(Loss==NULL && 拥塞窗口cwnd<Th){
		send_seg(data,拥塞窗口cwnd*MSS);
		while(ACK) 拥塞窗口cwnd++;
	}
	
	// 拥塞避免或线性增长
	While(Loss==NULL){
		send_seg(data,拥塞窗口cwnd*MSS);
		if(for all ACKs){
			拥塞窗口cwnd++;
		}
	}
	Th=拥塞窗口cwnd/2
	if(SIM_ACK==3)拥塞窗口cwnd=Th;
	if(timeout)拥塞窗口cwnd=1;
goto BEGIN;
```
