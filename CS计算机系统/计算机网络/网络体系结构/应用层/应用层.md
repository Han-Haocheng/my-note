# 应用层

应用层 application layer：是通过应用进程间的交互来完成特定网络应用，应用进程间通信和交互的规则
 - 协议：DNS、HTTP、SMTP 等
 - 数据单位：报文(message)
- 支持用户通过用户代理器或网络接口使用网络服务

## 功能

- 对话控制 dialog controlling：建立维护
- 同步 synchronization：在数据流中插入同步点

语法和语义 syntax and semantics：处理交换信息的语法和语义问题
- 数据表示转化：转化为主机独立编码
- 加密解密
- 压缩解压缩
