# DNS服务

域名解析系统DNS（Domain Name System）：是多层命名服务器构成的分布式数据库，将域名解析为IP地址，是互联网的核心功能，负载均衡
- 使用分布式：服务冗余、分散流量、距离适中、维护性好
- 分层：根服务器->顶级域名服务器->域名服务器

[[层次域名空间]]

## 流程

### 迭代查询

![[Pasted image 20251022143543.png]]

迭代查询：被查询服务器返回域名解析服务器的名字
1. 用户发起请求
2. 三级接力寻找
	1. 本地域名服务器问根域名服务器
	2. 本地域名服务器问顶级域名服务器
	3. 本地域名服务器问权威域名服务器
3. 获取最终答案
4. 结果反馈用户

### 递归查询
![[Pasted image 20251022143700.png]]

递归查询：将域名解析的任务交给所联系的服务器
1. 用户发起请求
2. 三级递归寻找
	1. 本地域名服务器问根域名服务器
	2. 根域名服务器问顶级域名服务器
	3. 顶级域名服务器问权威域名服务器
3. 获取最终答案
4. 结果反馈用户

### 记录缓存和更新

1. 域名解析服务器获得域名IP映射的同时缓存
2. 经过一段时间后，缓存条目失效
3. 本地域名服务器一般会缓存顶级域名服务器的映射

# DNS域名解析协议



DNS协议：查询query回复reply协议，消息格式相同
- 基于[[UDP用户数据报协议]]

## 格式
### 资源记录RR
资源记录RR（resource records）：格式为`(name, value, type, ttl)`
- type=A：name=主机域名，value=IP地址
- type=NS：name=域，value=权威域名解析服务器的主机域名
- type=CNAME：name=域名别名，value=真实域名
- type=MX：value是与name相对的邮件服务器


### DNS消息

消息头部
- identification：16位查询编号，回复用相同编号
- flags：查询、回复、期望递归、递归可用、权威回答
- questions：查询的名字和类型
- answers：查询的记录
- authority：权威服务器的记录
- additional information：可能使用的额外帮助信息

## DNS注册域名

1. 在域名管理机构注册域名
	- 提供权威域名解析服务器的名字和IP地址
	- 向顶级域名解析服务器中插入两条记录：type=NS，type=A
2. 在权威域名服务器中添加域名
