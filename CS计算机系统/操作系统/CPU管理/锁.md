# 锁

**锁**：保证互斥的同步机制，能保证临界区中操作数据的一致性，是一种包含*空闲*和*上锁*状态的共享变量

## 基本操作
锁有两个基本操作：闭锁和开锁

### 开锁


开锁操作只需一步：打开锁，即把锁状态修改为空闲状态。
开锁就是相关工作完成后，将锁打开，其他进程/线程就可以进入

### 闭锁

闭锁就是将锁锁上，其他进程/线程不能进入；了。
闭锁操作有两个步骤：等待锁达到打开状态；获得锁并锁上。闭锁的两个操作应该是原子操作，不能分开，否则就会留下穿插的空档，造成锁的功效丧失。可行的方法是采用原子级汇编指令 test and set 和 swap 等。

## 特性

- 锁的初始状态需为打开状态
- 进临界区前必须获得锁
- 出临界区时必须打开锁
- 如果其他进程/线程持有锁则必须等待
