# 内存管理


内存管理：操作系统负责完成内存的分配回收、地址转换、空间扩充、保护等功能
- *内存空间的分配与回收*：由操作系统完成主存储器空间的分配和管理，对程序员来说这些操作都是透明的，提高了编程效率。操作系统通过相应结构来记录内存空间的使用情况，完成内存空间的分配，并及时回收系统或用户释放的内存空间。
- [[地址转换]]
- *内存空间的扩充*：利用虚拟存储技术或自动覆盖技术，从逻辑上扩充内存。
- *存储保护*：保证各道作业在各自的存储空间内运行，互不干扰

## 使用


```c
int main(int argc,char*argv[]){
	int i,to,sum = 0;

	for(i = 0;i<=to;++i){
		sum += i;
	}
	printf("%d",sum);

```

- 编译程序

```
.text
_entry:
	call _main          ; call 40
	call _exit
_main:                ; addr-40
	mov [300],0
	ret
```

- 内存使用：将程序存放到内存中，PC 指向开始地址
- 内存指针需要根据程序的位置重新定位

```
		.text

```

### 编译时重定位

在编译时期，定位程序存放位置
- 优点：简单直接，效率高
- 缺点：系统运行死板，不能交换运行程序
- 适用：固定系统的单片机

### 运行时重定位


在程序从磁盘中载入时，根据程序 PCB 中保存的基地址(base)，进行重定位
- 优点：程序运行灵活，
- 缺点：效率降低，内存利用率低
- 地址翻译：每执行一条指令，要根据基地址和偏移地址计算出物理地址
- 交换(swap)：当程序进行等待时，将程序存放进磁盘，将就绪的程序从磁盘中加载到内存中
