# 快表

![[2025-09-08_153708.svg]]


快表TLB：据有并行查找能力的一组相联快速存储寄存器，用于存储当前访问的一些页表项，以加速

- 近似访存 1 次：要求 TLB 命中率高
- 通常大小：$[64,1024]$
- 64 能起效的原理：程序的地址访问存在空间局部性质[^1]


## 计算

$有效访问时间=HitR\times(TLB+MA)+(1-HitR)\times(TLB+n\times MA)$
- TBL访问时间TLB
- 内存访问时间MA
- 命中率HitR
- 多级列表级数n


| TLB | Cache | Page | 访存次数 | 访问外存次数 |
| --- | ----- | ---- | ---- | ------ |
| 命中  | 命中    | 命中   | 0    | 0      |
| 命中  | 缺失    | 命中   | 1    | 0      |
| 缺失  | 命中    | 命中   | 1    | 0      |
| 缺失  | 缺失    | 命中   | 2    | 0      |
| 缺失  | 缺失    | 缺失   | 2    | 1      |

- 快表命中，页表命中
- cache 命中，页表一定命中



[^1]: 空间局部性（Locality in Space）：程序多体现为循环、顺序结构
