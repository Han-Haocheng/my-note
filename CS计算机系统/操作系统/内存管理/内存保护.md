# 内存

**内存保护**：是为了防止某些作业可能会有意或无意地破坏操作系统或其他作业，常见的内存保护方法有界限寄存器方法和存储保护键方法。
## 方法

采用界限寄存器方法实现内存保护通常有在 CPU 中设置上、下界寄存器与基址和限长寄存器

### 上下界寄存器
**上下界寄存器方法**：用寄存器分别存放作业的结束地址和开始地址。在作业运行过程中，将每一个访问内存的地址与这两个寄存器中的内容进行比较，判断是否越界，如若越界，便产生保护性中断。

### 基址和限长寄存器
**基址和限长寄存器方法**。采用基址和限长寄存器分别存放作业的起始地址及作业的地址空间长度，基址寄存器也叫重定位寄存器，限长寄存器也叫界地址寄存器。在作业运行过程中，将每个访向内存的相对地址和重定位寄存器中的值相加，形成作业的物理地址；限长寄存器与相对地址进行比较，若超过了限长寄存器的值，则发出越界中断信号，并停止作业的运行。
