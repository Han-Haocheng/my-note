# 分段

分段：将程序，根据用途和特点划分为不同的段，其中代码段/数据段不会增长

内存分段：将程序各个段，分别放入内存，通过段地址+偏移获取对应地址，通过PSD中的进程段表保存对应的地址址

![[2025-09-07_100239.svg]]
进程段表（LDT）：保存一个进程的内存段基址


分段：段式管理方式按照用户进程中的自然段划分逻辑空间，逻辑地址由段号 S 与段内偏移量 W 两部分组成。

| 31 … 16 | 15 … 0 |
| 段号 S | 段内偏移量 W |

段表：每个进程都有一张逻辑空间与内存空间映射的段表，其中每个段表项对应进程的一段，段表项记录该段在内存中的始址和长度。在配置了段表后，进程在执行时，首先通过查找段表找到每个段所对应的内存区，实现从逻辑段到物理内存区的映射。

| 段号  | 基址   | 长度   | 权限  |
| --- | ---- | ---- | --- |
| 0   | 180K | 150K | R   |
| 1   | 360K | 60K  | R/W |
| 2   | 70K  | 110K | R/W |
| 3   | 460K | 40K  | R   |
