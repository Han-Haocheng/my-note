# 内存分配

内存分配：是指操作系统根据进程的需求，为其分配适量的内存空间

## 过程
1. 请求内存：进程向 OS 发出内存请求，提出对内存量的需求。
2. 检查可用性：OS 检查当前可用的内存资源，判断是否满足进程的请求。
3. 分配内存：如果满足进程的需求，OS 会为进程分配所需的内存空间，并更新内存管理数据结构以记录这次分配。
4. 返回地址：OS 将分配的内存地址返回给进程，让进程通过该地址来访问内存。在内存分配过程中，OS 可能会采用多种策略，来优化内存使用和提高分配效率


## 方式

### 连续分配管理

连续分配管理方式：是指为一个用户程序分配一片连续的内存空间
- 包括[[静态分区]]和[[动态分区]]

### 分页存储管理

分页存储管理：在为进程分配内存时，以[[块]]为单位将进程中的若干个[[页]]分别装入到多个可以不相邻接的[[物理块]]中
