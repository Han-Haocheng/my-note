
# 磁盘

![[Pasted image 20260607102723.png]]
![[2025-09-15_165832.svg]]


磁盘（Disk）：典型的直接存取设备，由涂有磁性物质的金属或塑料盘片构成，通过磁头的导体线圈从磁盘存取数据


## 结构

### 基本组成

磁道：盘面上存储数据的同心圆

扇区：磁道沿径向分成的大小相等区域（通常 512 B），磁盘可寻址的最小存储单位

柱面：与盘片中心等距的所有磁道的集合

### 地址表示


- 磁盘地址 = 柱面号 · 盘面号 · 扇区号（块号）
- 物理记录块数 = 扇区数 × 磁道数 × 磁盘面数

## 访问时间

磁盘访问三步骤：磁头寻道 → 等待扇区旋转到位 → 数据读写

- 磁盘访问时间 $Ta = Ts + 1/(2r) + b/(rN)$

- 例：寻道 + 旋转延迟平均 20 ms，传输速率 10 MB/s，传输 10 KB → 总访问时间 21 ms

### 寻道时间
寻道时间：磁盘接收到读指令后，磁头从当前位置移动到目标磁道位置所需花费的时间
- $T_s = m \times n + s$
- $m$ 为常数（与磁盘驱动器速度有关），$n$ 为移动磁道数，$s$ 为启动磁臂时间
- 若题目未给出启动时间 $s$，则忽略不计
### 旋转延迟时间

旋转延迟时间：扇区移动到磁盘下所需的平均旋转延迟时间 
- $T_r = 1/(2r)$
- $r$ 为磁盘旋转速度，平均旋转延迟 = 磁盘旋转半周的时间
- 硬盘的旋转速度为 15000 r/min，每转需时 4 ms，平均旋转延迟时间为 2 ms
### 传输时间

传输时间：从磁盘上读出数据或向磁盘中写入数据所需要的时间 
- $Tt = b/(rN)$  
- $b$ 为读/写字节数，$N$ 为一条磁道上的字节数，$r$ 为每秒转数  
- 当 $b = N/2$ 时，$Tt$ 与 $Tt$ 相同  

## 类型

固定头磁盘  
  - 每个盘面所有磁道各配一个读/写磁头  
  - 可并行读/写，有效提高磁盘 I/O 速度  
  - 通常用于大容量磁盘  


活动头（移动头）磁盘：每个盘面只配一个磁头  
  - 需先寻道再串行读写，I/O 速度较慢  
  - 结构简单，适合中小型磁盘设备

## 操作

### 低级格式化

低级格式化：在对磁盘进行数据存储之前，磁盘必须分成扇区以便磁盘控制器能进行读和写操作，将磁盘分成扇区以便控制器读写操作
- 每个扇区由头部、数据区域（512 B）和尾部组成
- 头部和尾部包含磁盘控制器使用的信息

### 高级格式化

高级格式化（逻辑格式化）：磁盘分区创建文件系统的过程，操作系统将初始文件系统数据结构存储到磁盘
- 包括建立根目录、初始化存储空间管理数据结构等

### 分区

磁盘分区：将物理磁盘划分为多个相互独立的逻辑磁盘，不同分区可使用不同的文件系统，必须有一个分区被标记为活动分区以引导启动  
### 坏块处理

IDE 简单磁盘坏块处理：坏扇区可手工处理（如 Format 命令扫描），坏扇区在 FAT 表中标明，程序不再使用  

SCSI 复杂磁盘坏块处理：控制器维护磁盘坏块链表 ，出厂低级格式化时初始化，使用中不断更新，保留备用块逻辑替代坏块（扇区备用方案）

算法示例

### 先来先服务 FCFS

![[2025-09-21_134333.svg]]

先来先服务FCFS：根据进程请求访问磁盘的先后次序调度，适合进程数目较少的磁盘 I/O 访问
- 算法公平、简单，每个进程按顺序得到处理
- 未对寻道优化，平均寻道时间可能较长

### 最短寻道时间优先 SSTF
![[2025-09-21_135049.svg]]

最短寻道时间优先SSTF
- 选择与当前磁头所在磁道距离最近的请求
- 每次寻道时间最短，性能优于 FCFS
- 不能保证平均寻道时间最短
- 可能导致远端请求长期得不到服务（饥饿现象）
### 扫描算法 SCAN
![[2025-09-21_135245.svg]]

扫描算法SCAN
- 在磁头当前移动方向上选择距离最近的请求
- 基于 SSTF 并规定了磁头移动方向
- 磁头移动规律类似电梯运行，也称电梯调度算法
- 具有较好寻道性能，避免了饥饿现象
- 不足：两端磁道请求最后得到服务
### 循环扫描算法 CSCAN

![[2025-09-21_135415.svg]]

循环扫描算法CSCAN
- SCAN 算法的改进，磁头单向移动
- 磁头自里向外移动到最外层后，快速返回起始端
- 返回过程中不服务任何请求
- 消除了 SCAN 算法中两端不公平的现象

```c
static void make_request(){
	struct request*req;
	req=request+NR_REQUEST;
	req->sector=bh->b_blocknr<<1; // 每次读写2个扇区
	add_request(major+blk_dev,req);
}

static void add_request(struct blk_dev_struct *dev,struct request *req){
	struct requset*tmp = dev->current_request;
	req->next=NULL;
	cli();//关中断
	for(;tmp->next;tmp=tmp->next)
		if((IN_ORDER(tmp,req)||!IN_ORDER(tmp,tmp->next))&&IN_ORDER(req,tmp->next))
			break;
	req->next=tmp->next;
	tmp->next=req;
	sti();
}

#define IN_ORDER(s1,s2)\
	((s1)->dev<(s2)->dev)||(s1)->dev==(s2)->dev\
	&&(s1)->sector<(s2)->sector))
```
