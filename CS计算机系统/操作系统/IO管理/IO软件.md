# IO 软件

IO 软件：用于确保 I/O 设备与 CPU 的并发性和统一标准接口的软件
- 目标：与具体设备无关、统一命名、错误处理、缓冲技术、设备的分配和释放、I/O 控制方式

- 将系统 I/O 功能组织成一系列的层次，每层利用下层提供的服务完成子功能
- 屏蔽功能实现细节，向上层提供服务
- 层间接口不变，某层软件不会影响上下层的变更
- 仅最低层涉及硬件的具体特性

### 中断处理程序

**中断处理程序**：保存被中断进程的 CPU 环境，转入中断处理程序处理，完后恢复现场并返回

作用：控制 I/O 设备和内存与 CPU 之间的数据传送的主要方式

特性：中断与硬件相关，I/O 设备的中断服务程序与任何进程无关

过程：
1. 唤醒被阻塞的驱动程序进程
2. 保护被中断进程的 CPU 环境
3. 分析中断原因
4. 进行中断处理
5. 恢复被中断进程的现场

### 设备驱动程序
**设备驱动程序**：与硬件直接相关，负责具体实现系统对设备发出的操作指令
配置方式：每类设备配置一个设备驱动程序
角色：I/O 进程与设备控制器之间的通信程序，为上层用户程序提供标准接口
工作流程：
1. 接收上层软件发来的抽象 I/O 要求（如 read()和 write()命令）
2. 将抽象要求转换为具体要求后发送给设备控制器
3. 控制 I/O 设备工作，同时将设备控制器的信号传输给上层
封装性：设备之间的具体差别被设备驱动程序所封装



### 用户层 I/O 软件

**用户层 I/O 软件**：实现与用户交互的接口，通过调用 I/O 库函数完成设备操作

系统调用：用户层软件获取操作系统的服务必须通过系统调用实现

常见层次实例：
1. 向设备寄存器写命令 → 设备驱动程序
2. 检查用户设备使用权限 → 设备独立性软件
3. 二进制整数转换为 ASCII 码打印 → 用户软件层（I/O 库函数）
4. 缓冲管理 → 设备独立性软件（I/O 公有操作）
