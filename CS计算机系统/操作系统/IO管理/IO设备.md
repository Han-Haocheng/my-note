# IO 设备

I/O 设备：指计算机系统中用于信息输入、输出和存储的所有外围设备

## 性能指标

性能指标：设备使用特性、数据传输速率、数据传输单位、设备共享属性

## 分类

分类方式：可根据不同的性能对 I/O 设备进行分类
  - 按使用特性分类：存储设备、人机交互设备、网络通信设备
  - 按数据传输速率分类：低速、中速、高速设备
  - 按数据传输单位分类：块设备、字符设备
  - 按设备共享属性分类：独占设备、共享设备、虚拟设备
### 按使用特性分类


存储设备：指外存辅存设备，用于存储各种信息
- 如磁盘、磁带等

人机交互设备：计算机与用户之间交互的设备，分为输入、输出和交互式设备
- 输入设备：键盘、鼠标等
- 输出设备：打印机、绘图仪等
- 交互式设备：显示器，同步显示用户命令及执行结果

网络通信设备：用于与远程设备通信的设备
- 如各种网络接口、调制解调器等

### 按数据传输速率分类
低速设备：传输速率为每秒几字节到数百字节
- 如键盘、鼠标等
中速设备：传输速率为每秒数千字节至数万字节
- 如行式打印机、激光打印机等
高速设备：传输速率为数十万字节至千兆字节
- 如磁带机、磁盘机、光盘机等
### 按数据传输单位分类
块设备：信息的存取和传输以数据块为单位，属于有结构设备
- 如磁盘：传输速率高、可寻址
字符设备：用于数据的输入和输出，以字符为单位，属于无结构设备
- 如交互式终端、打印机：传输速率低、不可寻址
- 通常采用中断驱动的方式进行输入输出
### 按设备共享属性分类

独占设备：单位时间内只允许一个进程访问的设备，属于临界资源
- 系统一旦将设备分配给进程，便被占用直到进程结束并释放
- 具有临界资源的特征及可能出现的问题

共享设备：单位时间内允许多个进程同时访问的设备
- 特点：可寻址、可随机访问
- 如磁盘

虚拟设备：通过虚拟技术将一台独占设备转换为多个逻辑设备，供多个进程同时使用
- 如利用 SPOOLing 技术实现虚拟打印机
