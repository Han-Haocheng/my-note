# 缓冲技术



缓冲技术： 缓和 CPU 与 I/O 设备间速度不匹配的矛盾
- 减少对 CPU 的中断频率，放宽对 CPU 中断响应时间的限制
- 解决基本数据单元大小（即数据块大小）不匹配的问题
- 提高 CPU 和 I/O 设备之间的并行性


## 实现方式
  

硬件缓冲区：成本高，除特殊用途外使用极少

内存缓冲区：在内存划出存储区，临时存放输入/输出数据


## 分类

单缓冲、双缓冲、循环缓冲、缓冲池

### 单缓冲

单缓冲：处理机与设备之间只设置一个缓冲区  
- T：数据块从 I/O 设备输入到缓冲区的时间
- M：处理机将数据块从缓冲区取走的时间
- C：处理机对数据块的处理时间

处理时间
- 输入时间 T 与处理时间 C 可并行
- 每块数据处理时间 = Max(C, T) + M
	- 当 T > C 时，处理时间为 T + M
	- 当 T < C 时，处理时间为 C + M

### 双缓冲
![[Pasted image 20260603184918.png]]

双缓冲（缓冲对换）：设备输入数据时，先将数据块输入到第一个缓冲区，装满后移至第二个缓冲区，处理机从第一个缓冲区取走数据进行处理

处理时间
- 处理时间、输入时间、取走时间可并行操作
- 每块数据处理时间 = Max(C + M, T)

优势
- 加快输入和输出速度，提高设备利用率
- 字符设备采用行输入时，通常能消除用户等待时间
- 用户输入完第一行后，可继续向第二缓冲区输入下一行


### 循环缓冲
![[Pasted image 20260603185216.png]]

**循环缓冲**：多个设备速度相差较大时，双缓冲区不能满足要求，将多缓冲区以循环形式组织，由多个缓冲区和多个指针组成

缓冲区类型
- 空缓冲区 R：用于装输入数据的空缓冲区
- 满缓冲区 G：已装满数据的缓冲区
- 工作缓冲区 C：计算进程正在使用的现行工作缓冲区

指针
- Nextg：指示计算进程下一个可用缓冲区 G
- Nexti：指示输入进程下次可用的空缓冲区 R
- Current：指示计算进程正在使用的缓冲区 C

### 缓冲池

![[Pasted image 20260603185359.png]]

缓冲池：公用缓冲池，可用于输入也可用于输出，解决专用缓冲导致内存利用率不高的问题

缓冲区类型
- 用于收容输入数据的工作缓冲区
- 用于提取输入数据的工作缓冲区
- 用于收容输出数据的工作缓冲区
- 用于提取输出数据的工作缓冲区
