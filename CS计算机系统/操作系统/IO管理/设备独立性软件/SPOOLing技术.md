### SPOOLing 技术


**SPOOLing 技术**：利用多道程序技术，用一道程序模拟脱机输入时的外围控制机功能，把低速 I/O 设备上的数据传送到高速磁盘上，再用另一道程序模拟脱机输出时外围控制机的功能，实现在主机直接控制下的脱机输入、输出功能

虚拟性
- 多道程序技术可将一台物理 CPU 虚拟为多台逻辑 CPU
- SPOOLing 技术可将一台物理 I/O 设备虚拟为多台逻辑 I/O 设备
- 将独占设备虚拟为若干个共享设备

作用
- 外围操作与 CPU 对数据的处理同时进行
- 缓解 CPU 高速性与 I/O 设备低速性间的矛盾

特点
- 提高了 I/O 的速度：将对低速 I/O 设备的操作变为对输入井或输出井的操作，缓解了 CPU 与低速 I/O 设备之间速度不匹配的矛盾
- 将独占设备改造为共享设备：并未为任何进程分配设备，只在输入井或输出井中为进程分配存储区和建立 I/O 请求表
- 实现了虚拟设备功能：
	- 宏观上：多个进程在同时使用一台独占设备
	- 微观上：每个进程独占的设备实际上只是逻辑上的设备

在磁盘上开辟两个存储区域
- 输入井：模拟脱机输入时的磁盘设备，暂存 I/O 设备输入的数据
- 输出井：模拟脱机输出时的磁盘设备，暂存用户程序的输出数据

在内存中开辟两个缓冲区
- 输入缓冲区：暂存由输入设备送来的数据，再传送到输入井
- 输出缓冲区：暂存从输出井送来的数据，再传送给输出设备

模拟脱机 I/O 时的外围控制机
- 输入进程 SPi：将数据从输入机通过输入缓冲区送到输入井，CPU 从输入井读入内存
- 和输出进程 SPo：将数据从内存送到输出井，待输出设备空闲时经输出缓冲区送出


实例

打印机是独占性设备：通过 SPOOLing 变成可供多个用户共享的设备，提高设备利用率

共享打印过程
- 输出进程在输出井中申请空闲磁盘块区，将要打印的数据送入其中
- 输出进程为用户申请空白请求打印表，填入打印要求，挂到请求打印队列
- 打印机空闲时，从队首取出请求打印表，从输出井传数据到缓冲区再打印
- 打印完后检查队列，若有等待请求则继续，直至队列为空则自我阻塞
