# 设备独立性软件

**设备独立性软件**：实现用户程序与设备驱动器的统一接口、设备命名、设备保护以及设备的分配与释放
- **设备独立性**（设备无关性）：应用程序独立于具体的物理设备
- 执行所有设备的公有操作，向用户层提供统一接口

## 设备

访问 I/O 设备时，必须将逻辑地址转换为物理地址
### 逻辑设备

**逻辑设备**：应用程序中定义，用于请求某种设备，增加分配灵活性

逻辑设备表LUT：表项包括逻辑设备名、物理设备名和设备驱动程序入口地址，应用程序通过逻辑设备名访问 I/O 设备，无需使用物理名，通过 LUT 找到对应物理设备和驱动程序入口地址

建立方式
- 整个系统设置一张 LUT：所有逻辑设备名不允许重名，适用于单用户系统
- 每个用户设置一张 LUT：用户登录时建立，放入进程的 PCB 中

### 物理设备

**物理设备**：系统实际执行时使用的设备
