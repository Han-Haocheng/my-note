# 统一设备接口




I/O 子系统的统一接口
- Linux 中的 I/O 子系统向内核中的其他部分提供了一个统一的标准设备接口  
- 这是通过 `include/linux/fs.h` 中的数据结构 file_operations 来完成的  


file_operations 结构的作用  
- 当应用程序对设备文件进行诸如 open、close、read、write 等操作时  
- Linux 内核将通过 file_operations 结构访问驱动程序提供的函数


## 驱动程序的编译方式

- 直接静态编译成内核的一部分
- 编译成可以动态加载的模块  


静态编译的缺点  
- 会增加内核的大小  
- 还要改动内核的源文件  
- 不能动态地卸载，不利于调试  
- 因此推荐使用模块方式
