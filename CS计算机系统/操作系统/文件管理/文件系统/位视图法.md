# 位视图法

位示图：利用二进制状态位来表示磁盘中每个盘块的使用情况，所有盘块所对应的二进制位构成一个集合，称为位示图。
通过每位的状态判断当前盘块是否使用：位值为“0”时表示对应的盘块空闲；位值为“1”时表示对应的盘块已分配，或者相反。
其结构可以用一个二维数组来表示 `map[i][j]`，位示图的数组下标从 0 开始。
盘块分配
- 首先按顺序扫描位示图，从中找出一个或一组二进制位为“0”的位。
- 将找到的二进制位转换成盘块号。假定位于第 i 行、第 j 列，则：`P = n(i-1) + j`。
- 最后修改位示图，使 `map[i][j] = 1`。
盘块回收
- 将要回收的盘块号转换为二维数组的行、列号：
	`i = (P-1) / n + 1`
	`j = (P-1) % n + 1`
- 修改回收区在位示图中对应的位，令 `map[i][j] = 0`。
