# 链队列

![[2026-01-16_200544.svg]]

链队列：链式存储结构的队列

头尾指针相同状态问题：当头尾指针相同时，既可以表示队空，也可以表示队满
- 解决方式1:少用一个元素空间，约定入队前测试尾指针在循环意义下加一后是否等于头指针

```c
q->front==q->rear; // 队空条件
(q->rear+1)%MaxSize == q->front; // 队满条件
```





## 实现

```c
typedef struct qnode{
	QelemType data;
	struct qnode*next;
}DataNode;

typedef struct{
	DataNode*front;
	DataNode*rear;
}LinkQuNode;
```

### 初始化


```c
void InitQueue(LinkQuNode*&q){
	q=(LInkQuNode*)malloc(sizeof(LinkQuNode));
	q->front=q->rear=NULL;
}
```

### 销毁

```c
void DestroyQueue(SqQueue*&q){
	// 初始化临时指针
	DataNode*pre=q->front,*p;
	
	// 过滤空队列情况
	if(pre==NULL){
		free(q);
		return;
	}
	
	// 初始化指向下一个节点
	p=pre->next;
	
	// 循环删除
	while(p!=NULL){
		free(pre);
		pre=p;
		p=p->next;
	}
	free(pre);
	free(q);
}
```
