## 实现

```c
#define MaxSize 100

typedef struct{
	QElemType data[MaxSize];
	int front,rear;
}SqQueue;
```


### 初始化


```c
void InitQueue(SqQueue*&q){
	q=(SqQueue*)malloc(sizeof(SqQueue));
	q->front=q->rear=0;
	return OK;
}
```


### 销毁

```c
void DestroyQueue(SqQueue*&q){
	free(q);
}
```
