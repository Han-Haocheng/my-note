### 十字链表

十字链表：链式存储结构，多用于有向图，每个顶点有一个节点，==每一条弧也有一个节点==

![[2026-01-28_212206.svg]]

- 数据域data：存储和顶点相关信息
- 指针域firstin：指向该顶点为==弧头==的第一条弧所对应的弧结点
- 指针域firstout：指向该顶点为==弧尾==的第一条弧所对应的弧结点

![[2026-01-28_212452.svg]]

- 尾域tailvex：指示弧尾顶点在图中的位置
- 头域headvex：指示弧头顶点在图中的位置
- 指针域hlink：指向弧头相同的下一条弧
- 指针域tlink：指向弧尾相同的下一条弧
- info域：指向该弧的相关信息，如权值

```c
/* 弧结点类型定义 */
#define MAX_VEX 30                  // 最大顶点数
typedef struct ArcNode {
    int tailvex, headvex;           // 尾结点和头结点在图中的位置
    InfoType *info;                // 与弧相关的信息,如权值
    struct ArcNode *hlink, *tlink;  // 弧结点类型定义
} ArcNode;
typedef struct VexNode {
    VexType data;                  // 顶点信息
    ArcNode *firstin, *firstout;    // 顶点结点类型定义
} VexNode;
typedef struct {
    int vexnum, arcnum;
    VexNode xlist[MAX_VEX];
} OLGraph;                        // 图的类型定义
```
