# 邻接多重表

邻接多重表：链式存储结构，多用于无向图，每条边用一个节点表示，顶点结构与邻接表相同

顶点结构
![[2026-01-29_210451.svg]]

- 数据域data：存储和顶点相关信息
- 指针域firstedge：指向依附于该节点的第一条边所对应的表节点

边结构
![[2026-01-29_211403.svg]]
- 标志域mark：用以标识该条边是否被访问过
- ivex和jvex域：分别保存该边所依附的两个顶点在图中的位置
- 指针域ilink：指向下一条依附于顶点ivex的边
- 指针域jlink：指向下一条依附于顶点jvex的边
- info域：保存该边的相关信息

无向图的邻接多重表存储表示
```c
#define MAX_VEX 20                // 最大顶点数
typedef emmu {unvisited,visited} VisitIf;
typedef struct EBox {
    VisitIf mark;                // 访问标记
    int ivex, jvex;              // 该边依附的两个结点在图中的位置
    struct EBox *ilink, *jlink;   // 分别指向依附于这两个顶点的下一条边
    InfoType *info;              // 该边信息指针
} EBox;                         // 弧边结点类型定义
typedef struct VexBox {
    VertexType data;             // 顶点信息
    EBox *firsedge;              // 指向依附于该顶点的第一条边
} VexBox;                       // 顶点结点类型定义
typedef struct {
    VexBox adjmulist[MAX_VEX];
    int vexnum, edgenum;         // 无向图的当前顶点数和边数
} AMLGraph;
```

# 邻接表

邻接表：链式存储，每个顶点建立一个链表，存储邻接节点及相关信息，每个单链表设置一个表头，表头通过顺序结构存储

![[2026-01-28_211144.svg]]
- 数据域data：存储顶点$V_{i}$信息
- 度degree：表头节点出度或入度
- 链域firstarc：指向单链表的第一个节点
- 邻接点域adjvex：表示与$V_{i}$的邻接的顶点位置
- 数据域info：与边有关信息，通常是权值
- 链域nextarc：指向下一个与$V_{i}$邻接边节点


```c
#define MAX_VEX 30
// 边节点
typedef struct ArcNode {
    int adjvex;// 该弧所指向的顶点的位置
    struct ArcNode *nextarc; // 指向下一条边的指针
    int info;// 与边或弧相关的信息,如权值等
} ArcNode;

//顶点节点
typedef struct VNode {
    VertexType data;// 顶点信息
    ArcNode *firstarc;// 指向第一条依附该顶点的弧的指针
} VNode, AdjList[MAX_VEX];

typedef struct {
    AdjList vertices;
	int vexnum; // 顶点数量
	int arcnum; // 弧的数量
    int kind;// 图的种类标志
} ALGraph;
```

#### 无向图邻接链表
- 顶点$V_{i}$的度：第$i$个链表的顶点数

#### 有向图邻接链表

有向图邻接链表：在有向图中，第$i$个链表中的顶点数是顶点$V_i$的出（或入）度，求入(或出)度必须遍历整个邻接表。
