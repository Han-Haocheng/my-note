
# 链表



![[20250404173032.svg]]

**链表**：用一组物*理位置任意的存储单元*来存放线性表的数据元素，元素的*逻辑次序和物理次序不一定相同*，n 个结点由指针链组成，n=0 时为空表
- **结点**：数据元素的存储映像，由数据域和指针域两部分组成
- **头指针**：指向链表中第一个结点的指针
- **首元结点**：链表中存储第一个数据元素 $a_{1}$ 的结点
- **头结点**：链表的首元结点之前附设的一个结点


表示空表方式
- 无头结点：头指针为空时，表示空表
- 有头结点：头结点指针域为空时表示空表
	- 便于处理首元结点：处理链表时，第一个位置上的操作与其他位置上一致
	- 便于处理空表和非空表：无论链表是否为空，头结点都是指向非空指针，处理统一

## 类型

- **单链表**：结点只有一个指针域
- **循环链表**：首尾相接的链表，表中的最后一个结点的指针域指向头结点，形成一个环形
	- 特点：从任意一结点出发均可以找到表中的其他结点
	- 判断结束：和头指针/尾指针相比
	- 操作头尾：使用*尾指针*可快速锁定头尾结点
- **双链表**：结点有两个指针域，分别指向其直接前驱和直接后继
	- 优点：查找任意节点的前驱节点的时间复杂度为 $O(1)$
- **双循环链表**：头结点前驱指针指向尾结点，尾结点的后继指针指向头结点


| 类型      | 查找表头结点<br>（首元结点） | 查找表尾结点 | 插节点 `*p` 的<br>前驱节点 |
| ------- | :--------------: | :----: | :--------------: |
| 单链表     |      $O(1)$      | $O(n)$ |      $N/A$       |
| 头指针循环链表 |      $O(1)$      | $O(n)$ |      $O(n)$      |
| 尾指针循环链表 |      $O(1)$      | $O(1)$ |      $O(n)$      |
| 双向循环链表  |      $O(1)$      | $O(1)$ |      $O(1)$      |

## 特点

- 存储位置：任意位置
- 顺序存取：访问时只能通过头指针进入链表，并依次顺序扫描其余结点

优点
- 节点空间可以动态申请和释放
- 数据元素的逻辑次序靠节点的指针来完成，插入和删除时，不需要移动数据元素

缺点
- 存储密度小：每个结点的指针域需额外占用存储空间。当每个节点的数据域所占字节不多时，指针域所占存储空间的比重显得很大
- 非随机存取结构：对任意节点的操作都要从头指针按照指针链查找，增加了算法的复杂度

void CreateList(SqList*&L,ElemType a[],int n){
	int i = 0,k = 0;
	L = (SqList*)malloc(n*sizeof(SqList));
	
	while(i<n){
		L->data[k]=a[i];
		k++;i++;
	}
	L->length = k;	
}

### 合并

合并两个线性表 $La$ 和 $Lb$（分别表示集合 $A$ 和 $B$），使 $La$ 更新为 $A \cup B$
- 时间复杂度：$O(mn)$

```c
void unionList(List& La, List& Lb){
	La_len=ListLength(La);
	Lb_len=ListLength(Lb);
	for(i=i;i<=Lb_len;i++){
		GetElem(Lb,i,e);
		if(!LocateElem(La,e)) ListInsert(&La, ++La_len, e);
	}
}
```
### 有序合并

有序顺序表合并：已知线性表 $La$ 和 $Lb$ 中的数据元素按值非递减有序排列，现要求将 $La$ 和 $Lb$ 归并为一个新的线性表 $Lc$，且 $Lc$ 中的数据元素仍按值非递减有序排列。
- 时间复杂度：$O(m+n)$
- 空间复杂度：$O(m+n)$

```c
void MergeList_Sq(SqList& La, SqList& Lb,SqList&Lc){
	pa = La.elem; pb = Lb.elem;
	Lc.length = LA.length + Lb.Length;
	Lc.elem = new ElemType[Lc.length];
	pc= LC.elem;
	pa_last = La.elem + La.length - 1;
	pb_last = Lb.elem + Lb.length - 1;
	while(pa<=pa_last && pb<=pb_last)
		*pc++ = *pa <= *pb ? *pa++ : *pb++
	while(pa <= pa_last) 
		*pc++ =*pa++;
	while(pb <= pb_last)
		*pb++ =*pa++;
}
```

### 获取指定位置元素

```c
int GetElem(SqList L,int i,ElemType&e){
    // 检查非法情况
    if(i<1||i>L.length) return ERROR;

    // 核心逻辑
    e=L.data[i-1];
    return OK;
}
```

- 时间复杂度：$T(n)=O(1)$



### 查找元素

线性表的顺序查找
- 时间复杂度：$T(n)=O(n)$
- 平均判断次数：$$ASL=\sum_{i=1}^{n}P_{i}C_{i}=\frac{1}{n}\sum_{i=1}^{n}=\frac{n+1}{2}$$
  - $P_{i}$：第 i 个记录被查找的概率
  - $C_{i}$：找到第 i 个记录需要比较的次数
```C
int LOCateElem(SqList L,ElemType e){
    // 核心逻辑
    for(int i=0;i<L.length;i++)
        if(L.data[i]==e) return i+1;
    return 0;
}
```


### 插入元素

顺序表插入：移动元素的次数依赖于表的长度和插入的位置
- 时间复杂度：$T(n)=O(n)$
- 平均移动次数：$E_{ins}=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$

```c
Status ListInsert_Sq(SqList *&L,int i,ElemType e)
{
	int j;
    //检查非法情况
    if(i<1||i>L.length+1) 
	    return ERROR;
    if(L.length==MAX_SIZE) 
	    return ERROR;
    i--;
    
    // 核心逻辑
    for(j=L.length;j>=i;j--)
        L->data[j]=L->data[j-1];
    L->data[i-1]=e;
    L->length++;
    return OK;
}
```


### 删除元素

顺序表删除元素
- 时间复杂度：$T(n)=O(n)$
- 平均移动次数：$$E_{del}=\frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{n-1}{2}$$

```c
Status ListDelete_Sq(SqList *&L,int i,ElemType &e){
    //检查非法情况
    if(i<1||i>L.length) 
	    return ERROR;
    i--;

    // 核心逻辑
    e=L.data[i-1];
    for(int j=i;j<L.length;j++)
        L->data[j-1]=L->data[j];
    L->length--;
    return OK;
}
```
