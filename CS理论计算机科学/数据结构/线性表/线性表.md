# 线性表

线性表：具有**相同特性**的数据元素的一个**有限序列**，数据元素之间的**关系是线性关系**




存储方式：[[顺序表]]、[[链表]]

顺序表和链表的比较

| 类型     | 顺序表                | 链表                   |
| ------ | ------------------ | -------------------- |
| 存储空间   | 预先分配               | 动态分配                 |
| 存储密度   | $=1$               | $<1$                 |
| 存取时间   | $O(1)$             | $O(n)$               |
| 插入删除时间 | $O(n)$             | $O(n)$               |
| 使用情况   | 表长变化不大<br>频繁随机访问元素 | 长度变化较大<br>频繁进行插入删除操作 |

## 逻辑特征

- 开始节点：有且只有一个、没有直接前趋、仅有一个直接后继
- 终端节点：有且仅有一个、没有直接后继、仅有一个直接前趋
- 内部节点：有且仅有一个直接前趋、有且仅有一个直接后继


## 抽象数据类型

### 数据对象

$D=\{ a_{i}|a_{i}\in \mathrm{Elemeset}, i=1,2,\dots,n\}$

$$(a_{1},a_{2},\dots ,a_{i-1},a_{i},a_{i+1},\dots,a_{n})$$
- $a_{1}$：线性起点/起始节点
- $a_{n}$：线性终点/终端节点
- $a_{i-1}$ 是 $a_{i}$ 的直接前趋
- $a_{i+1}$ 是 $a_{i}$ 的直接后继
- $1,2,\dots,n$：下标，表示元素在线性表中的位置
- $n$：表长/元素的总个数
- $n=0$：空线性表

### 数据关系

- $R=\{ <a_{i-1},a_{i}>|a_{i-1},a_{i}\in D,(i=2,3,\dots,n) \}$

### 基本操作


| 操作                    | 含义                            |
| --------------------- | ----------------------------- |
| `InitList(&L)`        | 构造一个空线性表L                     |
| `DestroyList(&L)`     | 销毁线性表L                        |
| `ClearList(&L)`       | 将线性表L重置为空表                    |
| `ListLength(L)`       | 返回线性表L中的元素个数                  |
| `GetElem(L,i,&e)`     | 用e返回线性表L中第i个数据元素的值            |
| `ListInsert(&L,i,e)`  | 在L的第i个位置插入新元素e<br>L的长度加一      |
| `ListDelete(&L,i,&e)` | 删除L的第i个元素<br>用e返回其值<br>L的长度减一 |

构造线性表：`InitList(&L)`

- 初始条件：无
- 操作结果：**构造**一个空的线性表

析构线性表：`DestroyList(&L)`

- 初始条件：线性表L已经存在
- 操作结果：**销毁**线性表L

清空线性表：`ClearList(&L)`

- 初始条件：线性表L已经存在
- 操作结果：将线性表L**重置为空表**

判断线性表为空：`ListEmpty(L)`

- 初始条件：线性表L已经存在
- 操作结果：判断线性表**是否为空**
  - TRUE：空表
  - FALSE：非空表

获取线性表长度：`ListLength(L)`

- 初始条件：线性表L已经存在
- 操作结果：返回线性表L中的**元素个数**

获取元素：`GetElem(L,i,&e)`

- 初始条件：线性表L已经存在
- 操作结果：用e返回线性表L中第i个数据元素的值

按要求获取元素：`LocateElem(L,e,compare())`

- 初始条件
	- 线性表L已经存在
	- compare是数据元素判定函数
	- 存在与e满足compare()的数据元素
- 操作结果：L中第1个符合条件的结果

获取元素前趋：`PriorElem(L,cur_e,&pre_e)`
- 初始条件
	- 线性表L已经存在
	- `cur_e`是L的元素
	- `cur_e`不是L的第一个元素
- 操作结果：用`pre_e`返回`cur_e`的前趋

获取元素后继：`NextElem(L,cur_e,&next_e)`
- 初始条件
	- 线性表L已经存在
	- `cur_e`是L的元素
	- `cur_e`不是L的最后一个元素
- 操作结果：用`next_e`返回`cur_e`的后继

插入新元素：`ListInsert(&L,i,e)`

- 初始条件
	- 线性表L已经存在
	- $1\leq i\leq ListLength(L)+1$
- 操作结果
	- 在L的第i个位置插入新的元素e
	- L的长度加一

删除元素：`ListDelete(&L,i,&e)`

- 初始条件
	- 线性表L已经存在
	- $1\leq i\leq ListLength(L)+1$
- 操作结果
	- 删除L的第i个元素
	- 用e返回其值
	- L的长度减一

遍历元素：`ListRraverse(&L,visited())`

- 初始条件：线性表L已经存在
- 操作结果：依次对线性表中每个元素调用`visited()`
