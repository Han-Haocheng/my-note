# 线性表

线性表：具有**相同特性**的数据元素的一个**有限序列**，数据元素之间的**关系是线性关系**

## 逻辑特征

- 开始节点：有且只有一个、没有直接前趋、仅有一个直接后继
- 终端节点：有且仅有一个、没有直接后继、仅有一个直接前趋
- 内部节点：有且仅有一个直接前趋、有且仅有一个直接后继


## 抽象数据类型

### 数据对象

$D=\{ a_{i}|a_{i}\in \mathrm{Elemeset}, i=1,2,\dots,n\}$

$$(a_{1},a_{2},\dots ,a_{i-1},a_{i},a_{i+1},\dots,a_{n})$$
- $a_{1}$：线性起点/起始节点
- $a_{n}$：线性终点/终端节点
- $a_{i-1}$ 是 $a_{i}$ 的直接前趋
- $a_{i+1}$ 是 $a_{i}$ 的直接后继
- $1,2,\dots,n$：下标，表示元素在线性表中的位置
- $n$：表长/元素的总个数
- $n=0$：空线性表

### 数据关系

- $R=\{ <a_{i-1},a_{i}>|a_{i-1},a_{i}\in D,(i=2,3,\dots,n) \}$

### 基本操作


| 操作                    | 含义                            |
| --------------------- | ----------------------------- |
| `InitList(&L)`        | 构造一个空线性表L                     |
| `DestroyList(&L)`     | 销毁线性表L                        |
| `ClearList(&L)`       | 将线性表L重置为空表                    |
| `ListLength(L)`       | 返回线性表L中的元素个数                  |
| `GetElem(L,i,&e)`     | 用e返回线性表L中第i个数据元素的值            |
| `ListInsert(&L,i,e)`  | 在L的第i个位置插入新元素e<br>L的长度加一      |
| `ListDelete(&L,i,&e)` | 删除L的第i个元素<br>用e返回其值<br>L的长度减一 |

构造线性表：`InitList(&L)`

- 初始条件：无
- 操作结果：**构造**一个空的线性表

析构线性表：`DestroyList(&L)`

- 初始条件：线性表L已经存在
- 操作结果：**销毁**线性表L

清空线性表：`ClearList(&L)`

- 初始条件：线性表L已经存在
- 操作结果：将线性表L**重置为空表**

判断线性表为空：`ListEmpty(L)`

- 初始条件：线性表L已经存在
- 操作结果：判断线性表**是否为空**
  - TRUE：空表
  - FALSE：非空表

获取线性表长度：`ListLength(L)`

- 初始条件：线性表L已经存在
- 操作结果：返回线性表L中的**元素个数**

获取元素：`GetElem(L,i,&e)`

- 初始条件：线性表L已经存在
- 操作结果：用e返回线性表L中第i个数据元素的值

按要求获取元素：`LocateElem(L,e,compare())`

- 初始条件
	- 线性表L已经存在
	- compare是数据元素判定函数
	- 存在与e满足compare()的数据元素
- 操作结果：L中第1个符合条件的结果

获取元素前趋：`PriorElem(L,cur_e,&pre_e)`
- 初始条件
	- 线性表L已经存在
	- `cur_e`是L的元素
	- `cur_e`不是L的第一个元素
- 操作结果：用`pre_e`返回`cur_e`的前趋

获取元素后继：`NextElem(L,cur_e,&next_e)`
- 初始条件
	- 线性表L已经存在
	- `cur_e`是L的元素
	- `cur_e`不是L的最后一个元素
- 操作结果：用`next_e`返回`cur_e`的后继

插入新元素：`ListInsert(&L,i,e)`

- 初始条件
	- 线性表L已经存在
	- $1\leq i\leq ListLength(L)+1$
- 操作结果
	- 在L的第i个位置插入新的元素e
	- L的长度加一

删除元素：`ListDelete(&L,i,&e)`

- 初始条件
	- 线性表L已经存在
	- $1\leq i\leq ListLength(L)+1$
- 操作结果
	- 删除L的第i个元素
	- 用e返回其值
	- L的长度减一

遍历元素：`ListRraverse(&L,visited())`

- 初始条件：线性表L已经存在
- 操作结果：依次对线性表中每个元素调用`visited()`

## 存储结构

[[顺序表]]、[[链表]]


顺序表和链表的比较

| 类型     | 顺序表                | 链表                   |
| ------ | ------------------ | -------------------- |
| 存储空间   | 预先分配               | 动态分配                 |
| 存储密度   | $=1$               | $<1$                 |
| 存取时间   | $O(1)$             | $O(n)$               |
| 插入删除时间 | $O(n)$             | $O(n)$               |
| 使用情况   | 表长变化不大<br>频繁随机访问元素 | 长度变化较大<br>频繁进行插入删除操作 |

### 销毁

顺序表销毁


链表销毁

```C
Status DestroyList_L(LinkList &L){
    Lnode *p;
    while(p){
        p=L;
        L=p->next;

    }
```

### 合并

合并两个线性表 $La$ 和 $Lb$（分别表示集合 $A$ 和$B$），使$La$ 更新为 $A \cup B$
- 时间复杂度：$O(mn)$

```c
void unionList(List& La, List& Lb){
	La_len=ListLength(La);
	Lb_len=ListLength(Lb);
	for(i=i;i<=Lb_len;i++){
		GetElem(Lb,i,e);
		if(!LocateElem(La,e)) ListInsert(&La, ++La_len, e);
	}
}
```


链表合并
- 时间复杂度：$O(1)$
```c
LinkList Connect(LinkList Ta,LinkList Tb){
	p = Ta->next;
	Ta->next = Tb->next->next;
	delete Tb->next
	Tb->next = p;
	return Tb;
}
```



有序顺序表合并：已知线性表 $La$ 和$Lb$ 中的数据元素按值非递减有序排列，现要求将 $La$ 和 $Lb$ 归并为一个新的线性表 $Lc$，且 $Lc$ 中的数据元素仍按值非递减有序排列。
- 时间复杂度：$O(m+n)$
- 空间复杂度：$O(m+n)$

```c

	pc= LC.elem;
```

- 时间复杂度：$O(m+n)$
- 空间复杂度：$O(1)$

```c
void MergeList_L(LinkList& La, LinkList& Lb, LinkList&Lc){
	pa=La->next;
	pb=Lb->next;
	pc=Lc=La
	while(pa&&pb){
		if(pa->data<=pb->data){
			pc->next=pa;
			pc=pa;
			pa=pa->next;
		}else{
			pc->next=pb;
			pc=pb;
			pb=>pb->next;
		}
	}
	pc->next = pa?pb;pb;
	delete Lb;
}
```

### 查找元素

线性表的顺序查找
- 时间复杂度：$T(n)=O(n)$
- 平均判断次数：$$ASL=\sum_{i=1}^{n}P_{i}C_{i}=\frac{1}{n}\sum_{i=1}^{n}=\frac{n+1}{2}$$
  - $P_{i}$：第i个记录被查找的概率
  - $C_{i}$：找到第i个记录需要比较的次数
```C
int LOCateElem(SqList L,ElemType e){
    // 核心逻辑
    for(int i=0;i<L.length;i++)
        if(L.data[i]==e) return i+1;
    return 0;
}
```


单链表获取指定元素位置
- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

```C
Status GetElem_L(LinkList L,int i, ElemType &e){
    int j=1;
    LinkList p=L->next;
    while(p&&j<i){
        p=p->next;
        j++;
    }
    if(!p||j>i) return ERROR;
    e=p->data;
    return OK;
}
```

```C
Lnode* LocateElem_L(LinkList L, Elemtype e){

	int j =1;
```

### 插入元素

顺序表插入：移动元素的次数依赖于表的长度和插入的位置
- 时间复杂度：$T(n)=O(n)$
- 平均移动次数：$E_{ins}=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$

```c
Status ListInsert_Sq(SqList *&L,int i,ElemType e)
{
	int j;
    //检查非法情况
    if(i<1||i>L.length+1) 
	    return ERROR;
    if(L.length==MAX_SIZE) 
	    return ERROR;
    i--;
    
    // 核心逻辑
    for(j=L.length;j>=i;j--)
        L->data[j]=L->data[j-1];
    L->data[i-1]=e;
    L->length++;
    return OK;
}
```

### 删除元素

顺序表删除元素
- 时间复杂度：$T(n)=O(n)$
- 平均移动次数：$$E_{del}=\frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{n-1}{2}$$

```c
Status ListDelete_Sq(SqList *&L,int i,ElemType &e){
    //检查非法情况
    if(i<1||i>L.length) 
	    return ERROR;
    i--;

    // 核心逻辑
    e=L.data[i-1];
    for(int j=i;j<L.length;j++)
        L->data[j-1]=L->data[j];
    L->length--;
    return OK;
}
```



单链表删除元素
- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

```c
Status ListDelete_L(LinkList&L,int i,ElemType&e){
	p=L; j=0;
	while(p->next && j<i-1){
		p=p->next;
		++j;
	}
	if(!p->next||j>i-1)
		return ERROR;
	q = p->next;
	p->next = q->next;
	e = q->data;
	delete q;
	return OK;
}
```
