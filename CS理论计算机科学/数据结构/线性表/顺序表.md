# 顺序表

![[20250410190959.svg]]

线性表顺序存储结构（线性表顺序映射、顺序表）：按逻辑顺序依次存放在一组地址连续的存储单元中
- 把逻**辑上相邻**的数据元素存储在**物理相邻**的存储单元中的存储结构
- 存储结构：**连续的存储空间**，随机存取
- 基地址/起始位置：线性表第一个元素的存储位置

## 特点
- 每个元素占用$l$个存储单元
- 已知第$i$个元素的位置，则第$i+1$个元素满足$LOC(a_{i+1})=LOC(a_{i})+l$
- 已知第1个元素的位置，则第i个元素满足：$LOC(a_{i})=LOC(a_{1})+(i-1)l$
- 任意元素均可随机存取

## 实现

- 存取元素的方法：随机存取法
- 存储密度：1
- 插入和删除操作时间长

静态数组表示

```c
#define LIST_INIT_SIZE 100 //定义线性表的最大长度
typedef struct{
    ElemType data[LIST_INIT_SIZE]; //用静态数组存储数据元素
    int length; //线性表的当前长度
}SqList; //顺序表的类型定义
```

动态数组表示

```c
#define LIST_MAX_SIZE 100 //定义线性表的最大长度
typedef struct{
    ElemType* data; //用静态数组存储数据元素
    int length; //线性表的当前长度
}SqList; //顺序表的类型定义

L.data=(ElemType*)malloc(LIST_MAX_SIZE*sizeof(ElemType));

```


### 构造

```C
Status InitList_L(LinkLIst&L){

```


**单链表头插法（前插法）**：元素插入在列表头部
- 时间复杂度：$O(n)$
```c
Status CreateList_H(LinkList*& L, ElemType a[],int n){
	LNode*s;
	int i;
	L=(LNode*)malloc(sizeof(LNode));
	L->next = NULL;
	for(i=0;i<n,i++){
		s=(LNode*)malloc(sizeof(LNode));
		s->data=a[i];
		s->next=L->next;
		L->next=s;
	}
}
```


**单链表尾插法（后差法）**：元素插入在列表尾部
- 时间复杂度：$O(n)$

```c
Status CreateList_R(LinkList*&L, ElemType a[],int n){
	LNode*s,*r;
	L->next = NULL;
	L=(LinkNode*)malloc(sizeof(LinkNode));
	
	r=L;
	for(i=0;i<n;++i){
		s=(LinkNode*)malloc(sizeof(LinkNode));
		s->data=a[i];
		r->next=s;
		r=s;
	}
	r->next=NULL;
}
```


**双链表头插法（前插法）**：元素插入在列表头部
- 时间复杂度：$O(n)$
![[2026-01-12_163354.svg]]
```c
Status CreateList_H(DLinkList*& L, ElemType a[],int n){
	// 初始化结构
	DLinkNode*s;
	int i;
	L=(DLinkList*)malloc(sizeof(DLinkNode));
	L->prior=L->next = NULL;

	// 初始化数据	
	for(i=0;i<n,i++){
		//生成新节点
		s=(DLinkNode*)malloc(sizeof(DLinkNode)); 
		s->data=a[i];
		
		// 数据关联
		s->next=L->next;
		s->prior=L;
		
		//断开头和旧后继的关联
		if(L->next!=NULL)
			L->next->prior=s;
		L->next=s;
	}
}
```

**双链表尾插法（后差法）**：元素插入在列表尾部
- 时间复杂度：$O(n)$
![[2026-01-12_163847.svg]]
```c
Status CreateList_R(LinkList*&L, ElemType a[],int n){
	LNode*s,*r;
	L->next = NULL;
	L=(LinkNode*)malloc(sizeof(LinkNode));
	r=L;
	
	for(i=0;i<n;++i){
		s=(LinkNode*)malloc(sizeof(LinkNode));
		s->data=a[i];
		r->next=s;s->prior=r;
		r=s;
	}
	r->next=NULL;
}
```
