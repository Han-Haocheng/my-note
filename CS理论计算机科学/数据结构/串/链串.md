# 链串

![[2026-05-16_112651.svg]]

**链串Linked String**：串的链式存储结构，便于进行插入和删除运算，但存储密度较低。结点可以存放一个字符，也可存放多个字符

## 实现

为便于进行串的操作，当以链表存储串值时，除头指针外还附设一个尾指针指示链串的最后一个结点，并给出当前串中的结点个数，即串的长度

```c
#define chunksize 100
typedef struct chunk{
    char ch[chunksize];
    chunk *next;
}chunk;

typedef struct{
    chunk *head,*tail;
    int curlen;  //串的当前长度
}Lstring;
```
