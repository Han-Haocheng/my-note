# 归并排序

**二路归并排序**：将两个有序序列归并成一个有序序列的过程。
- **归并**：将两个或两个以上的有序序列归并成一个有序序列的过程。

二路归并排序基本思想
1. 将待排序的$n$个元素看成$n$个有序的子序列，每个子序列的长度为1
2. 然后两两归并，得到$\left\lceil \frac{n}{2} \right\rceil$个长度为2或1（最后一个有序序列的长度可能为1）的有序子序列；
3. 再两两归并，得到$\left\lceil \frac{n}{4} \right\rceil$个长度为4或小于4（最后一个有序序列的长度可能小于4）的有序子序列；
4. 再两两归并，……
5. 直至得到一个长度为$n$的有序序列。


## 实现
- 两个数据类型数组 `A[]` 和 `B[]`，以及三个整数 `pa`、`pb`、`pc`（用于标记序列的边界）
```c
void Merge(int sourceArr[],int tempArr[], int startIndex, int midIndex, int endIndex){
    int i = startIndex, j=midIndex+1, k = startIndex;
    while(i!= midIndex+1 && j != endIndex+1) { // 有一个指针到边界
    	tempArr[k++] = sourceArr[i] > sourceArr[j]
    		? sourceArr[j++]
    		: sourceArr[i++]; // 比较左右两边谁大
    }
    // 将剩余的部分复制到源列表中
    while(i != midIndex+1) tempArr[k++] = sourceArr[i++];
    while(j != endIndex+1) tempArr[k++] = sourceArr[j++];
    // 将临时列表已经排好序的代码
    for(i=startIndex; i<=endIndex; i++) sourceArr[i] = tempArr[i];
}
```

```c
//内部使用递归
void MergeSort(int sourceArr[], int tempArr[], int startIndex, int endIndex) {
    int midIndex;
    if(startIndex >= endIndex) // 条件
    	return
	midIndex = startIndex + (endIndex - startIndex) / 2;//避免溢出int
	MergeSort(sourceArr, tempArr, startIndex, midIndex); // 左区间排序
	MergeSort(sourceArr, tempArr, midIndex+1, endIndex); // 右区间排序
	Merge(sourceArr, tempArr, startIndex, midIndex, endIndex); // 归并
}
```  

## 算法分析  
- *时间复杂度*：$T(n)=O(n\log_2 n)$  
  归并排序的时间复杂度由“分治”过程的递归深度（$\log_2 n$）和每次归并的线性扫描（$n$）共同决定，因此整体为 $O(n\log_2 n)$。  
- *空间复杂度*：$S(n)=O(n)$  
  归并过程中需要额外的数组（如 `B[]`）存储中间结果，空间消耗与待排序元素数量 $n$ 成正比。  
- *稳定性*：稳定  
  归并排序在合并过程中，若遇到相等元素，会优先保留前一个序列的元素，因此不会改变相等元素的相对顺序
