## 快速排序
快速排序：通过对关键字的比较和交换，以待排序序列中的某个数据为基准元素（或称枢轴元素，可以是第一个、最后一个或中间位置的元素）
- 1962年由Hore提出的一种排序算法

## 流程
1. 将待排序序列分成两个部分
	- 其中左半部分数据小于等于基准元素
	- 右半部分数据大于基准元素
2. 然后对左右两部分分别进行快速排序的递归处理
3. 直到整个序列按关键字有序为止
## 实现

```c
void quicksort (datatype data[], int low, int high) {
    if(low<high) {
        int pivotkey=partition (data,low,high);  // 确定枢轴
        quicksort (data, low, pivotkey-1);      // 递归排序
        quicksort (data, pivotkey+1, high);     // 递归排序
    }
}

int partition (datatype data[], int low, int high) {
    datatype pivotkey=data[low];  // 选择第1个数据元素为枢轴
```

## 算法分析
时间复杂度：
- 最好情况$T(n)=O(n\log_2 n)$
  当每次都将待排序序列划分成两个长度相等的子列
- 最坏情况$T(n)=O(n^2)$
  如每次划分都只得到一个子列时
- 平均情况$T(n)=O(n\log_2 n)$

空间复杂度（需栈空间实现递归）
- 最坏情况：$S(n)=O(n)$
  要进行$n-1$次递归调用
- 平均情况$S(n)=O(\log_2 n)$
  其容量与递归调用的最大层数一样

稳定性：是不稳定的排序方法
