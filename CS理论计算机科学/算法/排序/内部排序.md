# 内部排序

**内部排序（内排序）**：在排序的整个过程中，待排序的所有记录全部被放置在内存中的排序方法

基本操作
- ==比较==关键字的大小
- 将记录从一个位置==移动==至另一个位置


- [[交换排序]]、[[基数排序]]、[[归并排序]]、[[插入排序]]、[[选择排序]]

## 分类

### 选择排序


选择排序：每一趟在后面 $n-i+1$ 个中选出关键字最小的对象，作为有序序列的第 $i$ 个记录。
- [[简单选择排序]]、[[堆排序]]

### 交换排序

交换排序：==两两比较==，如果发生逆序则交换，直到所有记录都排好序为止。
- [[冒泡排序]]、[[快速排序]]



### 插入排序

- [[直接插入排序]]、[[折半插入排序]]、[[希尔排序]]


## 约定
- 数据的存储可以是顺序、链式
- 待排序数据采用顺序储存结构，利用一维数组r存储。
- 排序都是将待排序的数据序列排列为升序或非降序序列。
- 为简化算法，数据的数据类型为整型。
- 待排序的数据个数用n表示。
- 本章中所涉及的序列$\{R_1, R_2, \ldots, R_n\}$均以其关键字代替，即用$\{K_1, K_2, \ldots, K_n\}$表示

## 比较

| 排序算法       | 最好情况           | 最坏情况           | 平均情况           | 空间复杂度         | 不稳定性 | 使用范围            |
| ---------- | -------------- | -------------- | -------------- | ------------- | ---- | --------------- |
| [[直接插入排序]] | $O(n)$         | $O(n^2)$       | $O(n^2)$       | $O(1)$        | 稳定   | 小规模<br>初始序列基本有序 |
| [[折半插入排序]] | $O(n\log_2 n)$ | $O(n^2)$       | $O(n^2)$       | $O(1)$        | 稳定   |                 |
| [[希尔排序]]   | -              | $O(n^2)$       | $O(n^{1.3})$   | $O(1)$        | 不稳定  |                 |
| [[冒泡排序]]   | $O(n)$         | $O(n^2)$       | $O(n^2)$       | $O(1)$        | 稳定   | 初始序列基本有序        |
| [[快速排序]]   | $O(n\log_2 n)$ | $O(n^2)$       | $O(n\log_2 n)$ | $O(\log_2 n)$ | 不稳定  | 大规模             |
| [[简单选择排序]] | $O(n^2)$       | $O(n^2)$       | $O(n^2)$       | $O(1)$        | 不稳定  | 小规模             |
| [[堆排序]]    | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(1)$        | 不稳定  | 大规模             |
| [[归并排序]]   | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n)$        | 稳定   | 大规模<br>有序表合并    |
| [[基数排序]]   | $O(d(n+r))$    | $O(d(n+r))$    | $O(d(n+r))$    | $O(n+r)$      | 稳定   | 关键字有明显结构特征      |

关键字有明显结构特征：字符串和整数这类关键字取值范围为有限
- 当关键字的取值范围属于某个无穷集合时，则不能使用基数排序算法，这时只有借助于“比较”的方法来排序

当记录很大(每个记录所占空间较多)时，时间耗费很大，可采用静态链表作存储结构
