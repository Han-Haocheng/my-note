## 线性表查找

线性表查找：在线性表中查找元素
- [[顺序查找]]、[[二分查找]]、[[分块查找]]

## 特点

- 顺序查找对表没有特殊要求
- 分块时数据块之间在物理上可不连续。所以可以达到插入、删除数据只涉及对应的块；另外，增加了索引的维护
- 折半查找要求表有序，所以若表的元素的插入与删除很频繁，维持表有序的工作量极大
- 在表不大时，一般直接使用顺序查找

## 对比

| 对比  | 顺序查找 | 折半查找 | 分块查找     |
| --- | ---- | ---- | -------- |
| 时间  | 差    | 好    | 一般       |
| 空间  | 无    | 无    | 有额外的索引数据 |
| 代码  | 简单   | 一般   | 复杂       |
