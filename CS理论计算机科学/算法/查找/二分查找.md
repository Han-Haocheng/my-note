# 二分查找

折半查找（二分查找）
- 适用条件：采用==顺序==存储结构的==有序==表

描述：在表ST中取位于中间的记录作为比较对象
1. 若中间记录的关键字与给定值相等，则查找成功；
2. 若中间记录的关键字大于给定值，则在中间记录的左半区继续查找；
3. 若中间记录的关键字小于给定值，则在中间记录的右半区继续查找
4. 不断重复上述过程，直到查找成功或者所查找的区域无记录，即查找失败


## 判定树

![[2026-05-15_154320.svg]]

**判定树**：树中每一个结点对应表中记录的位置序号，把当前查找区间的中间位置作为根，左右子表分别作为根的左右子树即可得到
## 过程
过程：设表长为$n$，$low$、$high$和$mid$分别指向待查记录所在区间的下界、上界和中间点，$key$为给定的待查值
1. 设置初始区间指针：$low=1$，$high=n$；
2. 若$low>high$，查找失败，返回查找失败信息；否则$mid = \left\lfloor \frac{low + high}{2} \right\rfloor$，并执行以下操作：
	- 若`key<ST.elm[mid].key`，则`high=mid-1`；重新执行2
	- 若`key> ST.elm[mid].key`，则`low=mid+1`；重新执行2
	- 若`key=ST.elm[mid].key`，查找成功，返回记录在表中的位置


## 分析

借助折半查找的判定树，求取平均查找长度，假定有序表的长度$n=2^h-1$，则判定树深度为$h=\log_2(n+1)$，假设表中每个记录的查找概率相等，则查找成功时折半查找的平均查找长度为：
$$ASL=\frac{1}{n}\sum_{j=1}^{h} j \cdot 2^{j-1} = \frac{n+1}{n} \log_2(n + 1) - 1 \approx \log_2(n + 1) - 1$$


## 实现

### 二分查找算法


```c
int SearchBin(SSTable ST, KeyType key) {
    // 在有序表中折半查找其关键字等于key的数据元素
    // 若找到,则函数值为该元素在表中的位置,否则为0
    int low = 0; // 查找区间左边界
    int high = ST.length-1; // 查找区间右边界
    while (low<=high) {
        int mid=(low+high)/2;
        
        if (key == ST.R[mid].key) return mid; // 找到待查元素   
        
        if (key<ST.R[mid].key) high=mid-1;  // 缩减右边界
        else low=mid+1;   // 缩减左边界
    }
    return -1; // 表中不存在待查元素
}
```
