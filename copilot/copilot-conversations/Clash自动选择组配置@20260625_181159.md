**ai**: 在 Clash 扩展配置中配置自动选择组（Auto Select Group），通常用于根据延迟或丢包率自动选择最优节点。以下是常见的配置方法：

## 1. 基础自动选择组配置

```yaml
proxy-groups:
  # 自动选择组 - 基于延迟测试
  - name: "Auto-Select"
    type: url-test
    proxies:
      - "节点1"
      - "节点2"
      - "节点3"
    url: "http://www.gstatic.com/generate_204"
    interval: 300
    tolerance: 50
    
  # 自动选择组 - 基于故障转移
  - name: "Auto-Fallback"
    type: fallback
    proxies:
      - "节点1"
      - "节点2"
      - "节点3"
    url: "http://www.gstatic.com/generate_204"
    interval: 300
```

## 2. 参数说明

| 参数 | 说明 |
|------|------|
| `type: url-test` | 自动选择延迟最低的节点 |
| `type: fallback` | 按顺序使用节点，失败时自动切换 |
| `url` | 用于测试的URL |
| `interval` | 测试间隔（秒） |
| `tolerance` | 延迟容差（毫秒），仅url-test类型可用 |

## 3. 完整配置示例

```yaml
proxy-groups:
  # 自动选择组
  - name: "Auto-Select"
    type: url-test
    proxies:
      - "🇭🇰 香港节点"
      - "🇯🇵 日本节点"
      - "🇺🇸 美国节点"
      - "🇸🇬 新加坡节点"
    url: "http://www.gstatic.com/generate_204"
    interval: 300
    tolerance: 50
    
  # 备用自动选择组
  - name: "Auto-Fallback"
    type: fallback
    proxies:
      - "🇭🇰 香港节点"
      - "🇯🇵 日本节点"
      - "🇺🇸 美国节点"
    url: "http://www.gstatic.com/generate_204"
    interval: 300
    
  # 规则组引用自动选择
  - name: "Global"
    type: select
    proxies:
      - "Auto-Select"
      - "Auto-Fallback"
      - "DIRECT"
```

## 4. 高级配置技巧

```yaml
proxy-groups:
  # 按地区自动选择
  - name: "Auto-Asia"
    type: url-test
    proxies:
      - "🇭🇰 香港01"
      - "🇭🇰 香港02"
      - "🇯🇵 日本01"
      - "🇸🇬 新加坡01"
    url: "http://www.gstatic.com/generate_204"
    interval: 300
    tolerance: 30
    
  # 混合策略
  - name: "Smart-Select"
    type: url-test
    proxies:
      - "Auto-Asia"
      - "🇺🇸 美国01"
      - "🇬🇧 英国01"
    url: "http://www.gstatic.com/generate_204"
    interval: 600
    tolerance: 100
```

## 5. 注意事项

- `tolerance` 值越小，切换越频繁，建议 30-100ms
- `interval` 建议 300-600 秒，避免频繁测试影响性能
- 测试URL建议使用 `http://www.gstatic.com/generate_204` 或 `http://cp.cloudflare.com/generate_204`
- 自动选择组可以嵌套使用，实现更精细的控制

配置完成后，在规则中引用自动选择组即可实现自动切换最优节点。
