# 一、三种数据交换方式（电路、报文、分组）的特点
1. 电路交换：整个报文的比特流连续地从源点直达终点。独占信道，通信质量好，但利用率不高，不适合突发数据。
2. 报文交换：整个报文先传送到相邻节点，全部存储下来之后查找转发表,转发到下一个节点。整个报文为单位，时延大。
3. 分组交换：单个分组（整个报文的一部分）传送到相邻节点，存储下来查找转发表，转发到下一个节点。动态分配带宽，利用率高且网络健壮，但存在时延和抖动，可能拥塞。

# 二、CSMA/CD 协议工作原理
1. 多点接入：多台计算机以多点接入的方式连接在一条总线上。
2. 载波监听：在发送数据之前和过程中，每个站都要不停的检测信道
3. 碰撞检测：检测到碰撞，停止发送，随机等待，再次发送。

# 三、五层网络体系结构及数据传递过程

| 五层网络体系结构 | 数据单元                   | 信息交互主体     |
| -------- | ---------------------- | ---------- |
| 应用层      | 报文                     | 应用进程间的     |
| 传输层      | TCP--报文段<br>UDP--用户数据报 | 两台主机中进程之间的 |
| 网络层      | IP数据报                  | 不同主机间的     |
| 数据链路层    | 帧                      | 相邻节点之间的    |
| 物理层      | 比特流                    | 设备         |

# 四、虚电路 vs 数据报服务的对比

| 对比方面              | 虚电路服务                       | 数据报服务                                 |     |
| ----------------- | --------------------------- | ------------------------------------- | --- |
| **思路**            | 可靠通信由**网络**保证               | 可靠通信由**用户主机**保证                       |     |
| **连接的建立**         | **面向连接**                    | **无连接**                               |     |
| **终点地址**          | 仅在**连接建立阶段**使用，每个分组使用端的虚电路号 | 每个分组都有**终点的完整地址**，即IP地址               |     |
| **分组的转发**         | 属于**同一条虚电路**的分组均由**同一路由**转发 | 每个分组**独立查找转发表**进行转发                   |     |
| **当节点出故障时**       | 所有通过出故障节点的虚电路**均不能工作**      | 出故障的节点可能会**丢失分组**，一些**路由**有可能发生**改变** |     |
| **分组的顺序**         | 按**发送顺序**到达节点               | **不一定**按发送顺序到达节点                      |     |
| **端到端的差错处理和流量控制** | 可由**网络**负责，也可由**用户主机**负责    | 由**用户主机**负责                           |     |

1. 集线器：
	1. 工作层次：物理层

# 七、2-13课后题 ：为什么要使用信道复用技术？常用信道复用技术有哪些？
### 为什么要使用信道复用技术
许多用户通过复用技术就可以共同使用一个共享信道进行通信，虽然复用要付出一定代价（有共享信道带宽较大，复用器和分用器等的成本），但如果复用的信道数量较大，在经济上也算合算。
### 常用信道复用技术有哪些
频分复用，时分复用，统计时分复用，波分复用，码分复用

# 八、3-04课后题 ： 数据链路层三个基本问题（封装成帧、透明传输、差错检测）为什么都要加以解决？
1. 封装成帧：用于界定数据，使接收方能识别帧的起止。
2. 透明传输：可防止数据中的特定比特组合被误判为帧的控制信息，确保数据内容不受限制。
3. 差错检测：能及时发现并丢弃出错的帧，避免无效数据继续在网络中传输，浪费带宽和处理能力。

# 九、4-03课后题  ：作为中间设备，转发器、网桥、路由器、网关有何区别？
1. 物理层的中间设备为转发器
2. 数据链路层的中间设备为网桥
3. 网络层的中间设备为路由器
4. 网络层以上使用的中间设备为网关

# 十、4-04课后题 ：IP、ARP、ICMP的作用
### 网际协议IP
**将世界上的异构网络统合到一个虚拟的网络**，在这个网络进行通信时，就像在一个网络上通信一样，看不见各网络的具体细节。
### 地址解析协议ARP
把一个主机的IP地址转换为相应的物理地址。
### 逆地址解析协议RARP
把一个主机的物理地址转换为相应的IP地址。
### 网际控制报文协议ICMP
是用来主机报告差错情况和提供有关异常情况的报告，更有效地转发IP数据报和提高交付成功的机会。

# 十一、4-07课后题：说明IP地址和硬件地址的区别。为什么要使用这两种不同的地址。
### 区别：
1. IP地址在网络层及以上使用的地址。
2. 硬件地址是数据链路层和物理层使用的地址。
### 为什么使用这两种地址：
全世界存在各种的网络,其使用不同的MAC地址，异构网络互相通信需要完成非常复杂的MAC地址转换工作，不可能由用户或用户主机完成。统一的IP地址使所有主机和异构网络连接到同一个虚拟的网络，软件通过调用ARP完成IP-MAC地址转换。

# 十二、1-03：试从多个方面比较电路交换、报文交换、分组交换的主要优缺点
1. 电路交换独占信道，通信质量稳定有保障，但线路利用率低，不适合突发数据。
2. 分组交换将数据分组，动态分配带宽，资源利用率高且网络健壮，但存在时延和抖动，可能拥塞。
3. 报文交换以整个报文为单位转发，时延大，现已基本淘汰。

# 十三、网络协议的三要素时什么？各有什么含义？
1. 语法：数据与控制信息的结构或格式
2. 语义：需要发出何种控制信息，完成何种动作以及做出何种响应。
3. 同步：事件实现顺序的详细说明。

# 十四、具有五层协议的网络体系结构的要点，包括各层的主要功能。
1. 应用层：直接为用户的应用进程提供服务。传递的是报文
2. 运输层：负责向两个主机进程之间的通信提供服务。传递的是报文段或用户数据报
3. 网络层：负责向分组交换网上的不同主机提供通信服务。传递的是IP数据报
4. 数据链路层：为两个相邻节点之间直接的传送数据。传递的是帧
5. 物理层：透明地传送比特流。传递的是比特流。
