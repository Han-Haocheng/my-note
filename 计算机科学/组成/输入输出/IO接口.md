# IO 接口

**IO 接口**：外部设备因为与 CPU 的速度、信号格式、数据格式不匹配，因此不能与 CPU 直接相连，相应在中间完成它们之间的速度匹配，信号转换和某些控制功能的电路
- IO 接口与设备之间不一定是一对一关系

## 功能

- 实现设备的选择
- 数据缓冲达到数据匹配
- 实现数据串--并格式转换
- 实现点评转换
- 传送控制命令
- 反应设备状态（忙、就绪、中断请求）

## 分类

### 根据外设和接口的数据传输方式

根据外设和接口的数据传输方式：实现数据格式的转换
- 串行接口
- 并行接口
### 根据 IO 控制方式

根据 IO 控制方式
- 程序查询接口
- 中断接口
- DMA 接口
### 根据功能灵活性

根据功能灵活性
- 可编程接口
- 不可编程接口


### 按通用性分类

按通用性分类
- 通用接口：Intel 8255、Intel 8251
- 专用接口：Intel 8279、Intel 8275

系统总线
- 数据线：传输 IO 数据、 IO控制信号字、IO 状态信号字、中断类型号、命令字
- 地址线：发送IO 端口地址
- 控制线：发送读写控制信号，中断请求信号、中断响应信号，仲裁信号，握手信号

寄存器：控制和状态两个寄存器因为，两个过程是分开的，所以可以合一
- 控制寄存器：用于保存 CPU 发出的用于控制 IO 设备的控制信号
- 状态寄存器：保存 IO 设备当前的运行状态
- 数据缓冲寄存器

### 设备状态

- 完成触发器 D
- 工作触发器 B
- 中断请求触发器 INTR
- 屏蔽触发器MASK

## 控制

1. 发命令：发送命令字到 IO 控制寄存器，通过驱动程序控制，向设备发送命令
2. 读状态：从状态寄存器读取状态字，获得设备或 IO 控制器的状态信息
3. 读写数据：从数据缓冲寄存器发送或读取数据，完成主机与外设的数据交换

### DMA 与程序中断的比较


|        | 中断方式   | DMA 方式 |
| ------ | ------ | ------ |
| 数据传送   | 程序     | 硬件     |
| 响应时间   | 指令执行结束 | 存取周期结束 |
| 处理异常情况 | 能      | 不能     |
| 中断请求   | 传送数据   | 后处理    |
| 优先级    | 低      | 高      |

> 思考：在一台主机中，可能出现多种类型的 IO 设备接口，用于处理速度不同的 IO 设备


| 比较维度   | 中断方式               | DMA方式                                  |
| ------ | ------------------ | -------------------------------------- |
| 数据传输   | CPU控制数据传输，每次一般传一个字 | DMA控制器控制数据传输，每次传一个块（但仍然是把块拆成一个字一个字的传输） |
| 中断请求   | 传送数据前发送            | 后处理，DMA控制器发送中断请求                       |
| CPU参与率 | 高，需要频繁处理中断         | 低，只需参与预处理和后处理，无需参与数据传输                 |
| 响应     | 指令执行周期结束/指令周期末     | CPU机器周期结束后响应，每次请求一个存取周期（总线周期）          |
| 适用场景   | 低速设备               | 高速大容量                                  |
| 优先级    |                    | DMA>中断                                 |


|                | 程序查询方式 | 中断方式 | DMA方式 |
|----------------|--------------|----------|---------|
| CPU和外设是否并行 | 否           | 是       | 是      |
| 传送数据过程和主程序是否并行 | 否           | 否       | 是      |
