# IO 接口

**IO 接口**：外部设备因为与 CPU 的速度、信号格式、数据格式不匹配，因此不能与 CPU 直接相连，相应在中间完成它们之间的速度匹配，信号转换和某些控制功能的电路
- IO 接口与设备之间不一定是一对一关系
## 功能

- 实现设备的选择
- 数据缓冲达到数据匹配
- 实现数据串--并格式转换
- 实现点评转换
- 传送控制命令
- 反应设备状态（忙、就绪、中断请求）

## 分类

### 根据外设和接口的数据传输方式

根据外设和接口的数据传输方式：实现数据格式的转换
- 串行接口
- 并行接口
### 根据 IO 控制方式

根据 IO 控制方式
- 程序查询接口
- 中断接口
- DMA 接口
### 根据功能灵活性

根据功能灵活性
- 可编程接口
- 不可编程接口

系统总线
- 数据线：传输 IO 数据、 IO控制信号字、IO 状态信号字、中断类型号、命令字
- 地址线：发送IO 端口地址
- 控制线：发送读写控制信号，中断请求信号、中断响应信号，仲裁信号，握手信号

寄存器：控制和状态两个寄存器因为，两个过程是分开的，所以可以合一
- 控制寄存器：用于保存 CPU 发出的用于控制 IO 设备的控制信号
- 状态寄存器：保存 IO 设备当前的运行状态
- 数据缓冲寄存器

- 设备选择线：单向、设备地址（接口地址）
- 数据线：双向、数据的输入输出
- 命令线：单向、CPU 向设备发出的指令
- 状态线：单向、设备状态

|功能|组成|
|-|-|
|选址功能|设备选择电路|
|传送命令功能|命令寄存器、命令译码器|
|传送数据功能|数据缓冲寄存器|
|反应设备状态功能|设备状态标记|

设备状态

- 完成触发器 D
- 工作触发器 B
- 中断请求触发器 INTR
- 屏蔽触发器MASK

## 调度

1. 发命令：发送命令字到 IO 控制寄存器，通过驱动程序控制，向设备发送命令
2. 读状态：从状态寄存器读取状态字，获得设备或 IO 控制器的状态信息
3. 读写数据：从数据缓冲寄存器发送或读取数据，完成主机与外设的数据交换


# 接口类型

- 按数据传送方式分类

  - 并行接口：Intel8255

  - 串行接口：Intel8251

- 按功能选择的灵活性

  - 可编程接口：Intel8255、Intel8251

  - 不可编程接口：Intel8212

- 按通用性分类

  - 通用接口：Intel8255、Intel8251

  - 专用接口：Intel8279、Intel8275

- 按照数据传送的控制方式分类

  - 中断接口：Intel8259

  - DMA接口：Intel8257
