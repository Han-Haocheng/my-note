# 屏蔽技术


屏蔽技术：改变处理优先等级，可以人为屏蔽某个中断源的请求



## 屏蔽触发器

![[Pasted image 20240305165730.png|20240305165730.png]]

屏蔽触发器：控制发出中断请求，控制排队器选择

- MASK=0（未屏蔽），INTR能被置1
- $MASK_i$=1（屏蔽），$INTP_i$=0（不能被排队器选中）

## 屏蔽字

16个中断源1-16按降序排列

| 优先级 | 屏蔽字              |
| ------ | ------------------- |
| 1      | 1111 1111 1111 1111 |
| 2      | 0111 1111 1111 1111 |
| 3      | 0011 1111 1111 1111 |
| 4      | 0001 1111 1111 1111 |
| 5      | 0000 1111 1111 1111 |
| 6      | 0000 0111 1111 1111 |
| 7      | 0000 0011 1111 1111 |
| 8      | 0000 0001 1111 1111 |
| 9      | 0000 0000 1111 1111 |
| 10     | 0000 0000 0111 1111 |
| 11     | 0000 0000 0011 1111 |
| 12     | 0000 0000 0001 1111 |
| 13     | 0000 0000 0000 1111 |
| 14     | 0000 0000 0000 0111 |
| 15     | 0000 0000 0000 0011 |
| 16     | 0000 0000 0000 0001 |

## 优先级


- 响应优先级：不可改变
- 处理优先级：可通过重新设置屏蔽字改变

| 中断源 | 原屏蔽字 | 新屏蔽字 |
| --- | ---- | ---- |
| A   | 1111 | 1111 |
| B   | 0111 | 0100 |
| C   | 0011 | 0110 |
| D   | 0001 | 0111 |

- 响应优先级：A->B->C->D 降序排列
- 处理优先级：A->D->C->B 降序排列

### 响应优先级

中断响应优先级：由硬件排队线路（也可通过程序逐个查询优先级）决定的，不可动态改变；

### 处理优先级

中断处理优先级：可以由中断屏蔽字来改变，反映的是正在处理的中断是否比新发生的中断的处理优先级低（屏蔽位为‘0’，对新中断开放），如果是的话，就中止正在处理的中断，转到新中断去处理，处理完后再回到刚才被中止的中断继续处理。


中断处理优先级为 ADCB

```mermaid
graph LR

```
