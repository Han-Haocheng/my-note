

```bash
sudo useradd yilong -m
sudo cat /etc/shadow | grep "yilong"

sudo usermod yilong -l chenglong
sudo cat /etc/shadow | grep "chenglong"

sudo groupadd sdufe
sudo cat /etc/group | grep "sdufe"

sudo gpasswd -a chenglong sdufe
groups chenglong

sudo su chenglong
cd
mkdir gongfu
ls -Al

touch gongfu/example.txt
ls -Al gongfu

echo "我在学习Linux" > gongfu/example.txt
cat gongfu/example.txt

mv gongfu/example.txt gongfu/text.doc
ls -Al gongfu

mkdir desktop 
mv gongfu/text.doc ~/desktop/
ls -Al desktop/
cat desktop/text.doc > Linux_1.2
cat Linux_1.2

exit
sudo passwd chenglong
sudo cat /etc/shadow | grep "chenglong"
groups chenglong
whoami
reboot

sudo groupdel -f sdufe
sudo userdel -r chenglong
sudo groupdel -f yilong
```


## 用户管理命令

查询相关操作：[[whoami]]、[[groups]]、[[id]]
 
添加相关操作
- [[useradd]]
- [[groupadd]]

修改相关操作
- [[gpasswd]]：管理 /etc/group 和 /etc/gshadow
- [[passwd]]：更改用户密码
- [[usermod]]：修改一个用户账户
- [[chage]]：修改帐号和密码的有效期限

删除相关操作
- [[groupdel]]：删除一个组
- [[userdel]]：删除用户账户和相关文件
