# 系统引导


![[Pasted image 20260531194428.png]]

操作系统引导：将 OS 内核装入内存并启动系统的过程
- 由启动引导程序完成，位于系统 ROM 中
- 三个阶段：初始引导 → 内核初始化 → 全系统初始化

## 流程

阶段 1：硬件初始化
- 电源启动：用户按下电源键，主板通电激活 CPU
- 执行 BIOS 程序
	- CPU 读取 ROM 芯片中的 BIOS 程序，执行硬件自检（POST）
		- 检查 CPU、内存、硬盘、键盘等关键设备状态
		- 故障则中止启动并报警，正常则显示硬件信息
	- BIOS 构建中断向量表，为后续操作提供基础服务

阶段 2：引导加载
- 加载启动设备
	- BIOS 按预设启动顺序（如硬盘→U 盘→光盘）检测存储设备
	- 首个包含有效引导标志的设备被选中，CPU 读取其引导扇区（首扇区，512 字节）
- 解析主引导记录（MBR）
	- MBR 包含：
		- 引导程序（446 字节）：定位活动分区
	    - 分区表（64 字节）：记录硬盘分区信息
	    - 结束标志（0 x 55 AA）
	- MBR 引导程序扫描分区表，找到标记为活动分区的条目

阶段 3：操作系统加载
- 加载分区引导记录（PBR）：CPU 读取活动分区的 PBR，定位启动管理器（如 bootmgr 或 GRUB）
- 启动管理器接管：提供多系统选择菜单（若有），加载用户所选操作系统的核心文件
- 加载操作系统内核：将操作系统初始化程序载入内存，初始化硬件驱动、启动系统服务，最终进入用户界面
